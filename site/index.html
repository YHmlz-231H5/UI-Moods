Component Library

One component implementation, 32 skins. Every value on this page comes from --um-* variables; which values those hold is decided entirely by the theme file linked above.

39 components documented. Every page is generated from the component's manifest.json — the examples, the API tables and the class names all come from one file.

Use it: link components/um-components.css and one themes/<id>.css, then write the classes. There is no build step and no JavaScript in the library.

Basic · 基础 1

Typography 文字排版 The set of text styles a page is written in: a title, a subtitle, a paragraph, supporting text, a link and a quote. The library paints the sizes, the colours and the leading; the words and the heading levels are the host's.

Form · 表单 13

Button 按钮 An action the user takes. The one component every interface needs, and the one that has to look right in thirty-two different moods. Checkbox 复选框 A box that either is ticked or is not, for choosing one or many things out of a list. The tick is a shape drawn in CSS, not a character. Checkbox Group 复选框组 A set of checkboxes that share one name and belong to one field. The group is a fieldset, so the browser groups the boxes for the form and for the screen reader. Date Picker 日期选择器 A field for a date. It is a real <input type="date"> inside a box the library draws, so the browser validates the date, the arrow keys walk through it and the reader's own calendar opens it. Field 表单项 The scaffolding around a control: a label, the control itself, and a line of text that says what to do next. It owns the spacing, so a form does not have to. Input / Textarea / Select 输入框 / 文本域 / 选择器 The three text controls a form is mostly made of: a single-line input, a multi-line textarea and a native select. One stylesheet gives all three the same border, focus ring and disabled treatment, so a form reads as one form. Input Number 数字输入框 A field for a number, with a pair of buttons that step it up and down. The buttons are real buttons, so they are in the tab order and the browser announces them; the browser's own spin buttons are taken away so there is only one pair. Radio 单选框 A round control for choosing exactly one option out of a set. Radios that share a name form a group, and the browser owns the exclusivity. Radio Group 单选框组 A set of radios that share one name and belong to one field. The group is a fieldset, so the browser groups the circles for the form and for the screen reader. Rate 评分 A row of stars the reader sets by choosing one. The stars are real radio buttons under a drawn shape, so the value is the browser's own value and the group is the browser's own group. Slider 滑块 A number picked by sliding along a track. It is a native range input, so the drag, the steps and the value are the platform's. Switch 开关 A binary setting that takes effect the moment it is flipped. The visible switch is drawn by the library; the control underneath it is a real checkbox. Upload 上传 A file input and the list of the files that were chosen. The input is a real one, so the browser's own dialog opens and the files are chosen with the browser's own picker.

Data · 数据展示 14

Avatar 头像 A small picture of a person. It takes a photo, a pair of initials or an icon, and it keeps the shape of whichever mood it is in. Badge 徽标 A small marker that counts or names a state, attached to something else. It comes in a solid fill and a soft tint, so a page can let what matters come forward and the rest recede. Card 卡片 A surface that groups one thing: a title, a body, a footer. Its border, radius, shadow and fill all come from the mood, so one card reads correctly in all thirty-two of them. Cascader 级联选择器 Options in levels, opened one level at a time. Every level is a disclosure, so the browser does the opening and the closing and the state survives a reload. Descriptions 描述列表 The facts about one thing, as label and value pairs. It is a definition list, so a screen reader announces each label before the value it belongs to. Empty 空状态 What a screen shows when there is nothing to show. It states the fact, and when there is a way out of it, it says what that way is. Progress 进度条 How much of something is done. The bar is a groove with a fill inside it, and the fill takes its width from the host. Result 结果 The end of a flow: one statement of what happened, a line of explanation, and the way out. It is the whole answer on one screen, not a toast that disappears. Skeleton 骨架屏 The shape of content that has not arrived yet. Three placeholder shapes and, if the motion is welcome, a shimmer over them. Statistic 统计数值 One number with the name of what it counts. The number is the largest thing on the block and everything else is sized around it. Table 表格 Rows of records in columns. It is a real table, so the column names travel with the cells and a screen reader can read a row across. Tag 标签 A label for one piece of data — a category, a state, a filter. The outlined member of the chip family, so it can sit beside a filled badge without either of them winning. Timeline 时间线 What happened, in order. An ordered list with a rail down one side and a dot at each entry, so the order is in the structure and not only in the picture. Transfer 穿梭框 Two lists side by side with a button between them: what is available on one side, what has been chosen on the other. The whole thing is a form, so the move is a submission.

Navigation · 导航 6

Breadcrumb 面包屑 The path to the page you are on, as a list of links. The separators between the steps are drawn by the stylesheet, not written into the markup as characters. Dropdown 下拉菜单 A row of actions that stays out of the way until it is wanted. The trigger is a <summary>, so the panel opens and closes with the browser's own disclosure behaviour. Menu 菜单 A list of places to go, with groups that fold away. The groups are <details> elements, so the browser opens and closes them and keeps them open across a reload. Pagination 分页 The pages of a long list, with the previous and next arrows at either end and the current page filled in. The arrows are chevrons drawn from two borders. Steps 步骤条 The order of a job, one step per entry, with the step you are on picked out and the steps already done marked as finished. Tabs 标签页 One row of tabs over several panels of content. The tabs are radio inputs, so the browser keeps the selection, the focus and the arrow keys without a line of script.

Feedback · 反馈 4

Alert 警告 A message that stays in the page and says what the reader has to know: the run failed, the quota is nearly gone, the sync is through. The variant colours the border and the mark, not the text. Loading 加载中 A ring that turns while the library waits for something. The ring is two borders with one side left out, and the turn is a keyframe, so it needs neither a timer nor a script. Popover 气泡卡片 A card that floats next to a trigger and holds more than a note: a heading, a body and a row of actions. The trigger is a <summary>, so the card opens and closes with the browser's own disclosure behaviour. Tooltip 文字提示 A short note that appears when the reader points at a word or tabs to it. The bubble is drawn by the stylesheet and placed with absolute positioning; the trigger is a real button, so the keyboard opens it as well as the pointer.

Others · 其他 1

Divider 分割线 A rule between two things. It can carry a label in the middle, drop the rules and keep the label, or stand up as a vertical rule.
