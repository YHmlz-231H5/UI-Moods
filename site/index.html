Component Library

One component implementation, 32 skins. Every value on this page comes from --um-* variables; which values those hold is decided entirely by the theme file linked above.

83 components documented. Every page is generated from the component's manifest.json — the examples, the API tables and the class names all come from one file.

Use it: link components/um-components.css and one themes/<id>.css, then write the classes. There is no build step and no JavaScript in the library.

Basic · 基础 14

Affix 固钉 A bar that stays where the reader put it while the page scrolls past. The bar is held with position: sticky, so the browser keeps it in the flow and pins it to the edge of the scrollport — no scroll listener, no measuring, no JavaScript. Border 边框 A frame of one semantic colour around a block of content. It says what state the content is in without adding a word to it. Color 色板 The semantic colours of the mood, drawn as a readable palette. Every cell names the role it shows and the address of the value behind it. Config Provider 全局配置 Element Plus's config provider is a Vue context: it hands the global size, the z-index, the locale and the namespace down to everything beneath it. A CSS-only library has no context to hand anything down, so this one is an attribute contract instead — a wrapper element carrying data-um-size and data-um-radius, and the library's own CSS answering to them. It sets the density and the radius mode of its subtree, and it says plainly that it cannot do the rest: there is no locale for it to set and no z-index for it to hand out. Container 容器 A fixed width, centred block of content. The width is a step of the type size rather than a number of pixels, so a mood with larger type gets a larger container. Icon 图标 The handful of marks a page needs most, drawn in CSS out of borders and pseudo-elements. The library ships no icon font, so every glyph here is a shape. Layout 布局 The skeleton of a page: a header, a side column, the content and a footer. It draws the rules that separate them and leaves the surfaces to the page behind it. Link 链接 A link, in one of the semantic colours. It is text, so it takes the text form of the colour and reads at 4.5:1 on the page, on an overlay and inside a container. PageHeader 页头 The title of a page, the line that says what the page is about, and the actions that belong to it. The title is a real heading at the level the page asks for, so the document outline stays right however the header is styled. Scrollbar 滚动条 A box that scrolls, with a scrollbar drawn in the mood's own colours instead of the platform's. The bar is a shape and a line, not a widget: there is no thumb to drag with a mouse, only a box that scrolls. Space 间距 A run of things with the same space between them. The space is one gap on the container, not a margin on each child, so the last child carries no trailing space and the run wraps without a gap of its own. Splitter 分割面板 Two panes with a divider between them. The divider is a line with a grip on it, and the grip says which way the thing can be moved. Moving it is the host's job: the library draws the shape and stops there. Text 文本 A run of inline text in one of the library's colours. It is the smallest atom of the type system: no box, no border, only the words and the colour they are written in. The blocks a page is written in are the typography component; this is the coloured run inside one of them. Typography 文字排版 The set of text styles a page is written in: a title, a subtitle, a paragraph, supporting text, a link and a quote. The library paints the sizes, the colours and the leading; the words and the heading levels are the host's.

Form · 表单 25

Autocomplete 自动补全 A text field that offers values while the reader types. The suggestions live in a native <datalist>, so the browser filters them, the arrow keys walk them and the popup opens without a line of script. Button 按钮 An action the user takes. The one component every interface needs, and the one that has to look right in thirty-two different moods. Checkbox 复选框 A box that either is ticked or is not, for choosing one or many things out of a list. The tick is a shape drawn in CSS, not a character. Checkbox Group 复选框组 A set of checkboxes that share one name and belong to one field. The group is a fieldset, so the browser groups the boxes for the form and for the screen reader. Color Picker 颜色选择器 A colour in three parts: the platform's own colour button, a row of palette chips the reader can pick from, and the hexadecimal value written out. The chips are a real radio group, so the choice is in the tab order and the browser announces it. Color Picker Panel 颜色选择面板 The panel a colour picker drops: the colours the host has predefined, a choice among the theme's own named colours, and the hexadecimal value written out. Every swatch is a real radio, so the choice is in the tab order and the browser announces it. Date Picker 日期选择器 A field for a date. It is a real <input type="date"> inside a box the library draws, so the browser validates the date, the arrow keys walk through it and the reader's own calendar opens it. Date Picker Panel 日期选择面板 The month panel a date picker drops: the month and its navigation, the week grid, and the two actions in the footer. The panel does not keep a month, so the host owns the month and the buttons that change it. Date Time Picker 日期时间选择器 A field for a date and a time together. It is a real <input type="datetime-local"> inside a box the library draws, so the browser validates both halves, the arrow keys walk the segments and the reader's own calendar opens it. Field 表单项 The scaffolding around a control: a label, the control itself, and a line of text that says what to do next. It owns the spacing, so a form does not have to. Input / Textarea / Select 输入框 / 文本域 / 选择器 The three text controls a form is mostly made of: a single-line input, a multi-line textarea and a native select. One stylesheet gives all three the same border, focus ring and disabled treatment, so a form reads as one form. Input Number 数字输入框 A field for a number, with a pair of buttons that step it up and down. The buttons are real buttons, so they are in the tab order and the browser announces them; the browser's own spin buttons are taken away so there is only one pair. Input OTP 验证码输入 A row of one-character fields for a code the reader has been sent. Each box is a real input that holds one character, so the browser's own keyboard, autofill and password manager all still apply to it. Input Tag 标签输入 A field that holds the tags already chosen, and an empty place to type the next one. Removing a tag needs a script; the shapes of the tag and of its remove button do not. Mention 提及 A field with a list of people under it. The reader types, the host decides which names to offer, and each name is a button that carries an avatar slot and an @name. Radio 单选框 A round control for choosing exactly one option out of a set. Radios that share a name form a group, and the browser owns the exclusivity. Radio Group 单选框组 A set of radios that share one name and belong to one field. The group is a fieldset, so the browser groups the circles for the form and for the screen reader. Rate 评分 A row of stars the reader sets by choosing one. The stars are real radio buttons under a drawn shape, so the value is the browser's own value and the group is the browser's own group. Slider 滑块 A number picked by sliding along a track. It is a native range input, so the drag, the steps and the value are the platform's. Switch 开关 A binary setting that takes effect the moment it is flipped. The visible switch is drawn by the library; the control underneath it is a real checkbox. Time Picker 时间选择器 A field for a time of day. It is a real <input type="time"> inside a box the library draws, so the browser validates the hour, the arrow keys walk the segments and the reader's own clock opens it. Time Select 时间选择器 A choice of time of day, as a native <select>. The option list is the platform's own, so the reader gets the system's own picker and its keyboard behaviour; the library draws the field and the arrow around it. Tree Select 树选择器 A tree you pick a leaf from. The branches are disclosures, so the browser opens and closes them, and the leaf that is picked is a real radio, so the browser keeps exactly one of them picked. Upload 上传 A file input and the list of the files that were chosen. The input is a real one, so the browser's own dialog opens and the files are chosen with the browser's own picker. Virtual Select 虚拟列表选择器 A long list of choices that the browser only lays out near the viewport. The rows far away are skipped, and the browser is told how tall such a row is, so the scrollbar is right without every row being built.

Data · 数据展示 24

Avatar 头像 A small picture of a person. It takes a photo, a pair of initials or an icon, and it keeps the shape of whichever mood it is in. Badge 徽标 A small marker that counts or names a state, attached to something else. It comes in a solid fill and a soft tint, so a page can let what matters come forward and the rest recede. Calendar 日历 One month laid out as a seven-column grid. It draws the month and marks the days; which month to show is the host's business, because a grid cannot know which months exist. Card 卡片 A surface that groups one thing: a title, a body, a footer. Its border, radius, shadow and fill all come from the mood, so one card reads correctly in all thirty-two of them. Carousel 轮播图 Slides the reader scrolls through, with a button at each end of a slide that moves to the neighbouring one. The track is a real scroller, so the browser does the scrolling and the snapping. Cascader 级联选择器 Options in levels, opened one level at a time. Every level is a disclosure, so the browser does the opening and the closing and the state survives a reload. Collapse 折叠面板 A panel that opens and closes. It is a real disclosure, so the browser does the opening and the closing and the state survives a reload. Descriptions 描述列表 The facts about one thing, as label and value pairs. It is a definition list, so a screen reader announces each label before the value it belongs to. Empty 空状态 What a screen shows when there is nothing to show. It states the fact, and when there is a way out of it, it says what that way is. Image 图片 A frame for a picture: it holds the space the picture will take, shows a placeholder while there is none, and decides how the picture fills that space. Infinite Scroll 无限滚动 A feed the reader can scroll a long way through, and a sentinel at the end of it that says what comes next. The library cannot load anything: it provides the container, the skipped layout and the sentinel, and the host decides what to load. Progress 进度条 How much of something is done. The bar is a groove with a fill inside it, and the fill takes its width from the host. Result 结果 The end of a flow: one statement of what happened, a line of explanation, and the way out. It is the whole answer on one screen, not a toast that disappears. Segmented 分段控制器 A row of choices that show which one is picked, drawn as radios under a shared frame. The browser keeps the selection, so the group behaves like the radio group it is. Skeleton 骨架屏 The shape of content that has not arrived yet. Three placeholder shapes and, if the motion is welcome, a shimmer over them. Statistic 统计数值 One number with the name of what it counts. The number is the largest thing on the block and everything else is sized around it. Table 表格 Rows of records in columns. It is a real table, so the column names travel with the cells and a screen reader can read a row across. Tag 标签 A label for one piece of data — a category, a state, a filter. The outlined member of the chip family, so it can sit beside a filled badge without either of them winning. Timeline 时间线 What happened, in order. An ordered list with a rail down one side and a dot at each entry, so the order is in the structure and not only in the picture. Tour 引导 A walkthrough that points at one thing on the page and says what to do with it. The ring is the thing being pointed at, the card is what the tour says, and the dots are how far along the walkthrough is. Moving from one step to the next is the host's job. Transfer 穿梭框 Two lists side by side with a button between them: what is available on one side, what has been chosen on the other. The whole thing is a form, so the move is a submission. Tree 树 Things inside things. Every branch is a disclosure, so the browser opens and closes it and the state survives a reload. Virtualized Table 虚拟表格 A long table the browser is not asked to lay out in full. The rows far from the viewport are skipped and given a placeholder size, so the cost of the list is what is near it. Virtualized Tree 虚拟树 A tree so large that the browser is asked to lay out only the branches near the reader. Every branch is still a disclosure, so the browser opens and closes it and the state survives a reload.

Navigation · 导航 8

Anchor 锚点 A column of links to the sections of the page, with a rule down the side so the reader can see that they are a list of places rather than a list of links. The section being read is marked with aria-current, because CSS cannot work out what is on screen. Backtop 回到顶部 A round button that takes the reader back to the top of the page. It is a link to a fragment, so it works with the keyboard alone and needs no scroll listener to appear — it is simply there. Breadcrumb 面包屑 The path to the page you are on, as a list of links. The separators between the steps are drawn by the stylesheet, not written into the markup as characters. Dropdown 下拉菜单 A row of actions that stays out of the way until it is wanted. The trigger is a <summary>, so the panel opens and closes with the browser's own disclosure behaviour. Menu 菜单 A list of places to go, with groups that fold away. The groups are <details> elements, so the browser opens and closes them and keeps them open across a reload. Pagination 分页 The pages of a long list, with the previous and next arrows at either end and the current page filled in. The arrows are chevrons drawn from two borders. Steps 步骤条 The order of a job, one step per entry, with the step you are on picked out and the steps already done marked as finished. Tabs 标签页 One row of tabs over several panels of content. The tabs are radio inputs, so the browser keeps the selection, the focus and the arrow keys without a line of script.

Feedback · 反馈 10

Alert 警告 A message that stays in the page and says what the reader has to know: the run failed, the quota is nearly gone, the sync is through. The variant colours the border and the mark, not the text. Dialog 对话框 A panel that asks the reader something, written as a <dialog>. It is shown the way a dialog is shown without JavaScript — open in the markup — and it is closed the way the browser closes one: the close button submits the form around it, and the form's method is dialog. Drawer 抽屉 A panel that slides out from the edge of the page: a side panel with a title, a body and a row of actions. It is held against the edge with fixed positioning, so it stays put while the page moves behind it. Loading 加载中 A ring that turns while the library waits for something. The ring is two borders with one side left out, and the turn is a keyframe, so it needs neither a timer nor a script. Message 消息 A short bar that tells the reader what just happened. Element Plus's message is a function that paints the bar and takes it away again; here the bar is a container, and the host decides whether it is on the page. Message Box 消息框 The narrow, centred box that asks the reader to confirm: a title, a message, and a pair of buttons, with an icon that carries the type. It is written as a <dialog> with a form around it, so the browser's own close is the one that closes it — the buttons are submits inside a form whose method is dialog, and the library installs no listener anywhere. Notification 通知 A card that reports something the reader did not ask about — a deployment finished, a certificate was renewed. It is wider than a message, and it carries a heading of its own. Popconfirm 气泡确认 A bubble that asks before it acts. It hangs off a trigger, and it holds a question and the two real buttons that answer it: confirm and cancel. Popover 气泡卡片 A card that floats next to a trigger and holds more than a note: a heading, a body and a row of actions. The trigger is a <summary>, so the card opens and closes with the browser's own disclosure behaviour. Tooltip 文字提示 A short note that appears when the reader points at a word or tabs to it. The bubble is drawn by the stylesheet and placed with absolute positioning; the trigger is a real button, so the keyboard opens it as well as the pointer.

Others · 其他 2

Divider 分割线 A rule between two things. It can carry a label in the middle, drop the rules and keep the label, or stand up as a vertical rule. Watermark 水印 A layer of the same word, repeated across a box, to say that what is underneath is a copy. The word is real text in the markup, tiled by the browser rather than baked into a picture.
