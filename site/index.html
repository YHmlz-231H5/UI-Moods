Component Library

One component implementation, 32 skins. Every value on this page comes from --um-* variables; which values those hold is decided entirely by the theme file linked above.

15 components documented. Every page is generated from the component's manifest.json — the examples, the API tables and the class names all come from one file.

Use it: link components/um-components.css and one themes/<id>.css, then write the classes. There is no build step and no JavaScript in the library.

Form · 表单 7

Button 按钮 An action the user takes. The one component every interface needs, and the one that has to look right in thirty-two different moods. Checkbox 复选框 A box that either is ticked or is not, for choosing one or many things out of a list. The tick is a shape drawn in CSS, not a character. Field 表单项 The scaffolding around a control: a label, the control itself, and a line of text that says what to do next. It owns the spacing, so a form does not have to. Input / Textarea / Select 输入框 / 文本域 / 选择器 The three text controls a form is mostly made of: a single-line input, a multi-line textarea and a native select. One stylesheet gives all three the same border, focus ring and disabled treatment, so a form reads as one form. Radio 单选框 A round control for choosing exactly one option out of a set. Radios that share a name form a group, and the browser owns the exclusivity. Slider 滑块 A number picked by sliding along a track. It is a native range input, so the drag, the steps and the value are the platform's. Switch 开关 A binary setting that takes effect the moment it is flipped. The visible switch is drawn by the library; the control underneath it is a real checkbox.

Data · 数据展示 6

Badge 徽标 A small marker that counts or names a state, attached to something else. It comes in a solid fill and a soft tint, so a page can let what matters come forward and the rest recede. Card 卡片 A surface that groups one thing: a title, a body, a footer. Its border, radius, shadow and fill all come from the mood, so one card reads correctly in all thirty-two of them. Empty 空状态 What a screen shows when there is nothing to show. It states the fact, and when there is a way out of it, it says what that way is. Progress 进度条 How much of something is done. The bar is a groove with a fill inside it, and the fill takes its width from the host. Skeleton 骨架屏 The shape of content that has not arrived yet. Three placeholder shapes and, if the motion is welcome, a shimmer over them. Tag 标签 A label for one piece of data — a category, a state, a filter. The outlined member of the chip family, so it can sit beside a filled badge without either of them winning.

Feedback · 反馈 1

Alert 警告 A message that stays in the page and says what the reader has to know: the run failed, the quota is nearly gone, the sync is through. The variant colours the border and the mark, not the text.

Others · 其他 1

Divider 分割线 A rule between two things. It can carry a label in the middle, drop the rules and keep the label, or stand up as a vertical rule.
