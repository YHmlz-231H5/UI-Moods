Slider 滑块

A number picked by sliding along a track. It is a native range input, so the drag, the steps and the value are the platform's.

input form since 1.1.0

The track is drawn twice, once for the WebKit pseudo-element and once for the Firefox one, and the thumb the same way. That duplication is the price of styling a native control: there is no single standard pseudo-element for either, so both engines get the same geometry instead of one of them getting the default.

Examples

A range · 取值范围
The bounds and the step are plain attributes. Whatever the browser shows for the value — the tooltip on some platforms — is not painted by the library, because that popup belongs to the platform.
<input class="um-slider" type="range" min="0" max="100" step="5" value="60" />
Disabled · 禁用
A disabled slider uses the real disabled attribute, so it is skipped by the tab order rather than only looking disabled.
<input class="um-slider" type="range" min="0" max="100" value="60" disabled />

Classes

ClassMeaning
um-sliderThe base class. Every instance carries it.
:disabledDisabled

Props

NameTypeDefaultDescription
minnumber0The lowest value the slider accepts.
maxnumber100The highest value the slider accepts.
stepnumber1How much one arrow key press moves the value.
valuenumber—The current value. It is written to the value attribute, so it round-trips through a form.
disabledbooleanfalseMakes the slider inert. It uses the real disabled attribute, so it leaves the tab order.

Events

NameDescription
inputFires while the value is being dragged or stepped. It is the browser's own event — the library installs no listener.
changeFires when the value is committed, at the end of a drag or when focus leaves the control.

Accessibility

Role: slider

Keyboard: Tab Arrow keys Home End Page Up Page Down

A real <input type="range">: the browser owns the drag, the arrow keys, Home and End, and the announcement of the value. The track and the thumb are painted through the vendor pseudo-elements, so the control has no child elements and no markup of its own to keep in sync.
