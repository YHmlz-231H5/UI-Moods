Mention 提及

A field with a list of people under it. The reader types, the host decides which names to offer, and each name is a button that carries an avatar slot and an @name.

div form since 1.1.0

Element Plus opens the list when the reader types an @ and closes it when they stop; here the list is a container and the host decides whether it is on the page. The input is a real input inside a borderless field, so the field and the text read as one control rather than as a field with something stuck to it. The field paints the surface and the input paints none — two translucent layers would be a colour no role names.

Examples

Basic · 基础用法
A field and the names under it. Each name is a button with an avatar slot in front of it.
<div class="um-mention">
  <div class="um-mention__field">
    <input class="um-mention__input" type="text" placeholder="Type @ to mention someone" aria-label="Comment">
  </div>
  <ul class="um-mention__list">
    <li>
      <button type="button" class="um-mention__item">
        <span class="um-mention__avatar" aria-hidden="true">ZM</span>
        <span class="um-mention__name">@Zhao Ming</span>
      </button>
    </li>
    <li>
      <button type="button" class="um-mention__item">
        <span class="um-mention__avatar" aria-hidden="true">LW</span>
        <span class="um-mention__name">@Li Wei</span>
      </button>
    </li>
    <li>
      <button type="button" class="um-mention__item">
        <span class="um-mention__avatar" aria-hidden="true">CY</span>

  </ul>
</div>

Props

NameTypeDefaultDescription
variantenum = bordered | plain | roundborderedThe shape of the field.
sizeenum = sm | md | lgmdThe height of the field and the size of its type.
valuestring—The text in the field.
placeholderstringType @ to mention someoneThe hint in the empty field.
labelstring—The accessible name of the field. It becomes the input's aria-label.
model-valuestring—The text in the field, bound with v-model in Vue. Leave it out and the `value` prop is the text; bind it and the field answers to the binding.
disabledbooleanfalseMakes the field inert. It uses the real disabled attribute on the input, so it leaves the tab order and the field paints the flat control surface.
readonlybooleanfalseKeeps the text visible but stops it being edited. It is the native readonly attribute, so the browser refuses the edit. The library does not repaint a read-only field — it is not a state it measures.
clearablebooleanfalsePuts a button at the end of the field that empties it. The button is a real one, so it is in the tab order.
loadingbooleanfalseSays the names are on their way. The mark appears in the field; the names themselves are the host's to bring.
prefixstring@The character that starts a mention. It is written in the field, the way the reader will see it in the sentence.
show-arrowbooleanfalsePuts the chevron at the end of the field, so the field says a list is behind it. The list here is a panel on the page, but it opens and closes with the field, so the arrow says what the reader cannot see.
typestringtextThe kind of field the input is. It is the input's own type attribute, so the browser brings its own keyboard and its own validation with it.
formstring—The id of the form the field belongs to. It is the input's own form attribute, so a field may live outside its form and still be submitted with it.

Slots

NameDescription
defaultThe names in the list. Each one is a list item holding a button.
headerThe line above the list of names.
footerThe line below the list of names.
labelThe name of one mention. The wrapper writes three names of its own when the caller has not written any, and this slot is what fills them; the caller's own names carry their own words.
loadingThe mark that says the names are on their way. It is drawn when the slot is empty and the caller's own when it is not.

Events

NameDescription
inputFires when the text in the field changes.
update:modelValueFires when the value changes, carrying the new value. This is the event `v-model` listens to.
searchFires on every keystroke in the field, carrying what has been typed. It is the same moment as the input event, under the name the mention gives it: the host is looking for names.
selectFires when one of the names is chosen, carrying the name. The wrapper reports it for the names it writes itself; a name the caller wrote is the caller's own button, so the caller wires it.
clearFires when the reader presses the clear button. The value goes with it, so the field is empty afterwards.

Accessibility

Keyboard: Tab Space

The field is a real text input, so the keyboard, the autofill and the screen reader all behave the way the reader expects. The names in the list are real buttons, so each one can be reached with the keyboard and pressed with Space — the library installs no listener and asks for no script. Give the input an accessible name: an aria-label, or a visible label above it. The list is not a listbox here: nothing tracks which name is active, so it is an ordinary list of buttons, and the reader reaches them by tabbing.
