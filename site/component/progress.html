Progress 进度条

How much of something is done. The bar is a groove with a fill inside it, and the fill takes its width from the host.

div data since 1.1.0

The width of the fill is set by the host, not by a class: it is a number that changes, and a class cannot carry a number. The track and the fill are both rounded, and the track hides what is behind it, so the fill never escapes the groove at any width.

Examples

Variants · 变体
The base class is the primary progress. The three modifiers paint the fill with the success, warning and danger colours instead.
<div class="um-progress">
  <div class="um-progress__track"><div class="um-progress__bar" style="width:68%"></div></div>
</div>
<div class="um-progress um-progress--success">
  <div class="um-progress__track"><div class="um-progress__bar" style="width:100%"></div></div>
</div>
<div class="um-progress um-progress--warning">
  <div class="um-progress__track"><div class="um-progress__bar" style="width:45%"></div></div>
</div>
<div class="um-progress um-progress--danger">
  <div class="um-progress__track"><div class="um-progress__bar" style="width:12%"></div></div>
</div>
With a label · 带文字
The label is a separate element, so it can be left out. The role and the aria values belong on the container, not on the bar.
68% of the plan limit 
<div class="um-progress" role="progressbar" aria-valuenow="68" aria-valuemin="0" aria-valuemax="100">
  <div class="um-progress__track"><div class="um-progress__bar" style="width:68%"></div></div>
  <span class="um-progress__label">68% of the plan limit</span>
</div>

Props

NameTypeDefaultDescription
variantenum = success | warning | danger—Which state the fill paints. The base class is already the primary progress, so a plain um-progress needs no modifier at all.
valuenumber0How much is done, as a percentage of the track. It is written to the inline width of the bar.
labelstring—The text under the bar.

Slots

NameDescription
labelThe text under the bar.

Accessibility

Role: progressbar

A progress bar is read, not operated: it is not focusable. Put role="progressbar" on the container with aria-valuenow, aria-valuemin and aria-valuemax, and the value is announced when it changes. The painted bar carries no value of its own, so the ARIA attributes are the whole contract.
