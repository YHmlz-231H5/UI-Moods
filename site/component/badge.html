Badge 徽标

A small marker that counts or names a state, attached to something else. It comes in a solid fill and a soft tint, so a page can let what matters come forward and the rest recede.

span data since 1.1.0

The soft badge deliberately carries no border. A border one step off its own fill sits at 1.06:1 in brutal and 1.97:1 in the brightest mood, so it reads as a smear rather than an edge — and it would differ from theme to theme. The tag is the outlined member of the family; the badge is the filled one.

Examples

Variants · 变体
The base class on its own is the neutral badge — a recessed fill in the mood's regular text colour. The five solid variants fill with the theme's own colour and take its matching on-colour, derived to reach 4.5:1.

<span class="um-badge">Neutral</span>
<span class="um-badge um-badge--primary">12</span>
<span class="um-badge um-badge--success">8</span>
<span class="um-badge um-badge--warning">3</span>
<span class="um-badge um-badge--danger">2</span>
<span class="um-badge um-badge--info">1</span>
Soft · 柔和
The soft badges tint toward the page, so they recede instead of competing. They carry no outline — the tag is the outlined member of this family.

<span class="um-badge um-badge--soft-primary">12</span>
<span class="um-badge um-badge--soft-success">8</span>

<span class="um-badge um-badge--soft-danger">2</span>
<span class="um-badge um-badge--soft-info">1</span>
Dot · 圆点
The dot takes the badge's own foreground colour, so it changes with the variant and needs no second colour.

Accessibility

The badge is text inside a plain <span>, so it is read where it sits and it is never focusable. When the count changes on its own, put the badge in a live region — role="status" — or the change is silent for anyone who cannot see it. A badge that only repeats what the label beside it already says can be marked aria-hidden instead.
