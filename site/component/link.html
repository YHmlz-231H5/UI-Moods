Link 链接

A link, in one of the semantic colours. It is text, so it takes the text form of the colour and reads at 4.5:1 on the page, on an overlay and inside a container.

a basic since 1.1.0

The link takes the text form of the colour, never the raw one: the raw brand colour is a fill colour, and on the brutal theme it is a bright yellow that clears 4.5:1 as a background and nothing at all as writing. The underline is a variant rather than a rule on the base class, because a page may want a link that is underlined at rest and a link that only underlines under the pointer, and the two are not the same thing.

Examples

The types · 各种类型
Each type takes the text form of its colour, so the link reads as text on the page, on an overlay and inside a container — the raw colour is a fill colour and is not guaranteed to read as writing.
Primary Success Warning Danger Info 
<a class="um-link um-link--primary" href="#">Primary</a>
<a class="um-link um-link--success" href="#">Success</a>
<a class="um-link um-link--warning" href="#">Warning</a>
<a class="um-link um-link--danger" href="#">Danger</a>
<a class="um-link um-link--info" href="#">Info</a>
States · 状态
A disabled link is announced as disabled and cannot be followed. It keeps its place in the tab order, because a reader who cannot follow it still has to know that it is there.
A link you can follow A link you cannot 
<a class="um-link um-link--primary" href="#">A link you can follow</a>
<a class="um-link um-link--primary" href="#" aria-disabled="true">A link you cannot</a>
Underlined · 带下划线
The underline is a variant of its own, so it can be combined with a type: a danger link may be underlined too.
Always underlined Danger, underlined 
<a class="um-link um-link--primary um-link--underline" href="#">Always underlined</a>
<a class="um-link um-link--danger um-link--underline" href="#">Danger, underlined</a>

Accessibility

Role: link

Keyboard: Tab Enter

A real <a href>, so it is in the tab order, it is announced as a link and it can be opened in a new tab from the browser's own menu. A disabled link uses aria-disabled rather than a class alone: it keeps its place in the tab order and is still announced, which is what a reader who cannot follow it needs to know. The stylesheet makes it inert to the pointer; a keyboard reader still reaches it, so the page has to refuse the activation — the Vue wrapper does that, and plain HTML has to do it in the link's own handler.
