Collapse 折叠面板

A panel that opens and closes. It is a real disclosure, so the browser does the opening and the closing and the state survives a reload.

details data since 1.1.0

A panel is a disclosure and not a menu: the browser owns the open state, so it stays open across a reload and the reader gets the collapsed and expanded announcement for free. The rule between two plain panels is drawn by the panel below as a top border, so a group of panels needs no wrapper and a group of one has no stray line above it. The arrow is drawn from two borders, so it takes the header's own colour and a disabled panel dims with it.

Examples

A group of panels · 一组面板
Two panels in a row. The rule between them is drawn by the panel below, so a group of panels needs no element around it. The first one is open.

Props

NameTypeDefaultDescription
openbooleanfalseOpens the panel. It is the native open attribute on the details, so the browser keeps the state.
variantenum = plain | cardplainThe shape of the panel. The plain run is the base class on its own; the card run adds um-collapse--card.
sizeenum = sm | md | lgmdThe size of the title and of the padding around the panel.
titlestring—The text of the header. A panel with no text needs an accessible name of its own.
model-valueboolean—Whether the panel is open, bound with v-model in Vue. Leave it out and the `open` prop is the state; bind it and the panel answers to the binding.
disabledbooleanfalseMakes the panel inert: it cannot be opened, and it takes the derived disabled colour.
expand-icon-positionenum = start | endendWhich end of the header the arrow sits on. The ends are written logically, so a right-to-left reader gets the other side; the end run is the base class on its own.

Slots

NameDescription
defaultThe body of the panel: what the panel hides and shows.

Events

NameDescription
toggleFires when the panel opens or closes. It is the browser's own event on the details — the library installs no listener.
update:modelValueFires when the panel opens or closes, carrying the new state. This is the event `v-model` listens to.

Accessibility

Role: group

Keyboard: Tab Enter Space

The panel is a real <details> and the header is a real <summary>, so the browser announces the header as a disclosure button and says whether the panel is open. The keyboard is the browser's own: Tab reaches the header, Enter or Space opens the panel. The arrow is drawn from borders, so it carries no text — the state is announced by the browser, not by the mark.
