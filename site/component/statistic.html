Statistic 统计数值

One number with the name of what it counts. The number is the largest thing on the block and everything else is sized around it.

div, span data since 1.1.0

The value takes the display size and the prefix and the suffix take the title size, so the eye lands on the number first and the unit is read beside it. The digits are set in equal-width figures: a row of statistics has to line up, and proportional digits move the number sideways every time the value changes.

Examples

A statistic · 一个统计值
The title says what is counted and the number is the largest thing in the block. The digits are equal width, so a column of these lines up.
Orders today 1,284 
<div class="um-statistic">
  <span class="um-statistic__title">Orders today</span>
  <span class="um-statistic__content">
    <span class="um-statistic__value">1,284</span>
  </span>
</div>
Prefix and suffix · 前缀和后缀
The prefix and the suffix take the title size and sit on the baseline of the number, so the unit reads as a unit and not as another number.
Revenue this month $ 48,920 USD 
<div class="um-statistic">
  <span class="um-statistic__title">Revenue this month</span>
  <span class="um-statistic__content">
    <span class="um-statistic__prefix">$</span>
    <span class="um-statistic__value">48,920</span>
    <span class="um-statistic__suffix">USD</span>
  </span>
</div>
States · 状态
Three variants paint the number. They use the colours derived for text, so the number stays readable on the page, on a card and inside a container.
Conversion 18.4 %
Jobs waiting 7
Failed checks 3 
<div class="um-statistic um-statistic--success">
  <span class="um-statistic__title">Conversion</span>
  <span class="um-statistic__content">
    <span class="um-statistic__value">18.4</span>
    <span class="um-statistic__suffix">%</span>
  </span>
</div>
<div class="um-statistic um-statistic--warning">
  <span class="um-statistic__title">Jobs waiting</span>
  <span class="um-statistic__content">
    <span class="um-statistic__value">7</span>
  </span>
</div>
<div class="um-statistic um-statistic--danger">
  <span class="um-statistic__title">Failed checks</span>
  <span class="um-statistic__content">
    <span class="um-statistic__value">3</span>
  </span>
</div>

Props

NameTypeDefaultDescription
variantenum = success | warning | danger—Which state the number reports. Without a variant the number is the ordinary text colour.
titlestring—What the number counts.
valuestring—The number, written the way it should be read: `9,999` and not `9999.0`.

Slots

NameDescription
prefixWhat stands in front of the number.
suffixWhat stands behind the number.

Accessibility

A statistic is read, not operated: nothing in it is focusable. The number is text, so it is announced as it is written. When the number is shortened for the eye — `9.9K` — the reader needs the full value, so put it in an aria-label on the content element; a screen reader cannot expand an abbreviation it does not know.
