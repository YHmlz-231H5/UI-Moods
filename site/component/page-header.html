PageHeader 页头

The title of a page, the line that says what the page is about, and the actions that belong to it. The title is a real heading at the level the page asks for, so the document outline stays right however the header is styled.

header, div, h1, p basic since 1.1.0

The title's level and its size are two different things, and this component keeps them apart: the class sets the size, the element sets the level. A header that is always an <h1> is wrong on every page that has a title of its own above it, and a header whose level follows its size is wrong on every page whose outline is not a list of font sizes.

Examples

Basic · 基础用法
A title, a subtitle and the actions that belong to the page. The buttons arrive without a class of their own, and the actions area gives them a shape; a button that brings its own class keeps it.

Deployment

Six replicas are moved to the new build, one at a time.

<header class="um-page-header">
  <div class="um-page-header__content">
    <h1 class="um-page-header__title">Deployment</h1>
    <p class="um-page-header__subtitle">Six replicas are moved to the new build, one at a time.</p>
  </div>
  <div class="um-page-header__actions">
    <button type="button">Roll back</button>
    <button type="button">Redeploy</button>
  </div>
</header>
Bordered · 带下边线
The bordered variant runs a rule under the header, so the header reads as a band above the page rather than as the first paragraph of it.

Audit log

Every change the connectors made, in the order they made it.

<header class="um-page-header um-page-header--bordered">
  <div class="um-page-header__content">
    <h1 class="um-page-header__title">Audit log</h1>
    <p class="um-page-header__subtitle">Every change the connectors made, in the order they made it.</p>
  </div>
  <div class="um-page-header__actions">
    <button type="button">Export</button>
  </div>
</header>

Props

NameTypeDefaultDescription
titlestring—The heading of the page.
subtitlestring—The line under the title that says what the page is about.
levelenum = 1 | 2 | 31Which heading level the title is. The class sets the size, so the level is free to follow the document outline instead of following the size.
variantenum = plain | borderedplainWhether a rule runs under the header. The plain header is the base class on its own; the bordered header adds um-page-header--bordered.

Slots

NameDescription
titleWhat is inside the heading.
subtitleWhat is inside the subtitle.
actionsThe actions that belong to the page.
extraThe actions that belong to the page. This is Element Plus's name for the `actions` slot; either one of them fills the actions area.
contentThe line under the title that says what the page is about. This is Element Plus's name for the `subtitle` slot; either one of them fills the line.
breadcrumbThe trail above the heading, for a page that says where it is.
defaultThe main content of the header, under the heading and its line.

Accessibility

Keyboard: Tab

The header is a <header> element, so it is the banner landmark of the section it sits in, and the reader hears it as such. The title is a real heading at the level the page asks for — the class sets the size, the element sets the level — so the reader can jump to it and the outline of the document stays true. The actions come after the title in the source, which is the order they are read in: what the page is, then what can be done to it.
