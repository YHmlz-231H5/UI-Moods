Message Box 消息框

The narrow, centred box that asks the reader to confirm: a title, a message, and a pair of buttons, with an icon that carries the type. It is written as a <dialog> with a form around it, so the browser's own close is the one that closes it — the buttons are submits inside a form whose method is dialog, and the library installs no listener anywhere.

dialog, form, h2, div, button, span feedback since 1.1.0

The icon is drawn from borders rather than written as a character, for the same reason the message bar's is: a character would have to be typed into every markup and would then be read out as a word. The disc of the icon and the fill of the confirm button are the same pair — the type's own colour and the theme's foreground for it — so the mark on the disc and the label on the button are both as legible as the theme has promised. The buttons are submits inside a form whose method is dialog, and the value on each one is the answer the host reads back from the dialog's returnValue, so the box can be closed and answered without a line of JavaScript.

Examples

Basic · 基础用法
A question with an answer. The three buttons are submits inside a form whose method is dialog, so each of them closes the box the way the browser closes one — and the cross is drawn from two borders, so it needs no icon font.

    <h2 class="um-message-box__title" id="um-message-box-title-basic">Archive this deployment?</h2>

    <button class="um-message-box__close" type="submit" value="close" aria-label="Close"></button>
    <div class="um-message-box__actions">
      <button class="um-message-box__cancel" type="submit" value="cancel">取消</button>
      <button class="um-message-box__confirm" type="submit" value="confirm">确定</button>
    </div>
  </form>
</dialog>

Disabled confirm · 禁用确定按钮
A confirm button that cannot be pressed yet. It is the real disabled attribute, so it leaves the tab order, and it is painted with the flattened control surface and the derived disabled colour rather than being dimmed with an opacity that nothing can measure.

Accessibility

Role: dialog

Keyboard: Tab Enter Escape

The box is a <dialog>, so the browser knows it is a dialog. It points at its title with aria-labelledby and at its message with aria-describedby, so the reader hears what the question is about and what it says, rather than a bare "dialog". The icon repeats what the type already says, so it is hidden from the reader. Every button is a real button inside a form whose method is dialog: submitting it is the browser's own way of closing a dialog, so the library installs no listener and handles no key, and the value on each button is the answer the host reads back from the dialog's returnValue. A static box is not modal — it does not take the focus, it does not make the page behind it inert, and Escape does not close it, because all three of those belong to showModal(), and that is JavaScript.
