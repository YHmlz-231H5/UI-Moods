Radio 单选框

A round control for choosing exactly one option out of a set. Radios that share a name form a group, and the browser owns the exclusivity.

input form since 1.1.0

The dot is a pseudo-element inside the circle that scales from zero to one, so the circle itself never changes size and the rows of a group stay aligned. The group is not a class: it is the shared name, which is why the browser can move the selection with the arrow keys without any JavaScript from us.

Examples

A group · 一组
Radios that share a name are one group: the browser lets exactly one of them be checked, and the arrow keys move the selection inside the group.
<label class="um-radio">
  <input class="um-radio__input" type="radio" name="um-radio-plan" checked />
  <span class="um-radio__dot"></span>
  <span class="um-radio__label">Monthly</span>
</label>
<label class="um-radio">
  <input class="um-radio__input" type="radio" name="um-radio-plan" />
  <span class="um-radio__dot"></span>
  <span class="um-radio__label">Yearly</span>
</label>
<label class="um-radio">
  <input class="um-radio__input" type="radio" name="um-radio-plan" disabled />
  <span class="um-radio__dot"></span>
  <span class="um-radio__label">Lifetime</span>
</label>

Accessibility

Role: radio

Keyboard: Tab Space Arrow keys

The circle is a real <input type="radio"> inside a <label>, and the drawn parts are spans. A group is a set of radios that share a name: the browser keeps exactly one of them checked, and the arrow keys move the selection inside the group while Tab moves between groups. The input is hidden visually rather than removed from the accessibility tree, so it keeps its place in the tab order and its label.
