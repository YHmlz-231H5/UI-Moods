Backtop 回到顶部

A round button that takes the reader back to the top of the page. It is a link to a fragment, so it works with the keyboard alone and needs no scroll listener to appear — it is simply there.

a, span navigation since 1.1.0

The button does not appear and disappear as the page scrolls. That would need a scroll listener, and a library with no JavaScript cannot have one — so the button is simply always there, and the page that wants it out of the way until the reader has scrolled is a page that writes the class itself. The arrow is drawn from two borders rather than shipped as a glyph, so it takes the theme's border colour and border weight and the library loads no icon font.

Examples

Basic · 基础用法
The button floats over the page in the corner, the way a back-to-top button has to: a link that scrolls away with the content is not a back-to-top link. The arrow is drawn from two borders, so it takes the button's own colour.
<a class="um-backtop" href="#top" aria-label="Back to top">
  <span class="um-backtop__icon" aria-hidden="true"></span>
</a>
In the flow · 随文
The inline variant sits in the flow of the page instead of floating over it, which is what the link at the end of a long article wants.

The audit ends at 14:20 and nothing was waiting for approval.

<p>The audit ends at 14:20 and nothing was waiting for approval.</p>
<a class="um-backtop um-backtop--inline" href="#top" aria-label="Back to top">
  <span class="um-backtop__icon" aria-hidden="true"></span>
</a>
Soft · 柔和
The soft fill is the brand colour's own tint, with the foreground derived for that tint. It fills in with the solid brand colour when the pointer is over it. It is shown here in the flow, so that both fills can be compared on one page.
<a class="um-backtop um-backtop--soft um-backtop--inline" href="#top" aria-label="Back to top">
  <span class="um-backtop__icon" aria-hidden="true"></span>
</a>

Props

NameTypeDefaultDescription
variantenum = solid | softsolidWhich fill the button has. The solid fill is the base class on its own; the soft fill adds um-backtop--soft.
sizeenum = sm | md | lgmdHow big the button is. The diameter follows the theme's control height, so the button grows with the mood's type rather than staying a fixed number of pixels.
inlinebooleanfalseWhether the button sits in the flow of the page instead of floating over it. It adds um-backtop--inline.
targetstring#topThe fragment the link points at. The page needs an element with that id for the link to go anywhere.
labelstringBack to topThe accessible name of the link. The arrow is a shape and says nothing, so the name has to come from somewhere.

Accessibility

Keyboard: Tab Enter

The button is an <a href="#top">: it is a link to a place on the page, so it is in the tab order, the browser announces it as a link, and it works with the keyboard alone. The arrow is aria-hidden and the link carries an aria-label, because a shape has nothing to say and the label is what names the control. The link points at a fragment, so the page needs an element with that id — a back-to-top link with no target goes nowhere, which is a property of the page rather than of the component.
