Field 表单项

The scaffolding around a control: a label, the control itself, and a line of text that says what to do next. It owns the spacing, so a form does not have to.

div form since 1.1.0

The field is a wrapper rather than a class you put on the control, because the control has to stay the element the platform knows about — a real input, a real select. The error modifier is the only state the field owns; the label and the message are muted roles, not a second theming system. The required asterisk is the one thing the field draws on the label, and it follows the control: a control that says it is required gets one, unless the form has asked for it to be left off.

Examples

Layout · 布局
A label, a control and a message. The field owns the gaps between them, so nothing here needs a margin of its own.
The name other people will see. 
<div class="um-field">
  <label class="um-field__label" for="um-field-name">Name</label>
  <input class="um-input" id="um-field-name" type="text" placeholder="Type here" />
  <span class="um-field__message">The name other people will see.</span>
</div>
Error · 错误
The error modifier reaches into the control: the border of the input, textarea or select inside the field turns to the danger colour, and the message stops being muted. The message is text, so it takes the derived danger text colour rather than the raw danger fill.
Enter a valid email address. 
<div class="um-field um-field--error">
  <label class="um-field__label" for="um-field-email">Email</label>
  <input class="um-input" id="um-field-email" type="text" value="not-an-email" />
  <span class="um-field__message">Enter a valid email address.</span>
</div>

Props

NameTypeDefaultDescription
errorbooleanfalsePuts the field in its error state.
validate-statusenum = error | success | warning | info—Which validation state the field is in. It is the class the state is painted with: um-field--error, um-field--success, um-field--warning or um-field--info.
disabledbooleanfalseSays the field is out of use. The field's own text dims. The control inside is the host's to disable, because it is the element that can actually be switched off.
inlinebooleanfalsePuts the label beside the control instead of above it.
sizeenum = sm | md | lgmdThe size of the control the field holds. The field does not redraw the control — it only tells it how tall it is. The medium size is the control's own size already.
hide-required-asteriskbooleanfalseTakes the asterisk after the label away. The asterisk follows the control — a control that says it is required gets one — so this is the way to say that the form does not want it.

Slots

NameDescription
labelThe label text, above the control.
messageThe helper or error text, below the control.
defaultThe control the field holds. It is the caller's own element, so the field can only point its label at it by looking for the id the caller gave it.
errorThe error text, below the control. It is shown in the error state, where it replaces the helper text.

Accessibility

The field is a plain container; the accessibility work is done by the label and the control. Use a real <label for> that points at the control's id, and aria-describedby when the message carries something the user needs to hear. The library paints the error state but does not announce it — that is the host's job.
