Anchor 锚点

A column of links to the sections of the page, with a rule down the side so the reader can see that they are a list of places rather than a list of links. The section being read is marked with aria-current, because CSS cannot work out what is on screen.

nav, ul, li, a navigation since 1.1.0

The rule is drawn on the entries rather than on the list, so it runs through the gaps between them instead of stopping at every word. That is why the column has no gap of its own: the space between two entries is the padding of the entry below. The current entry is marked with aria-current rather than with a class the page toggles, because the marking is information about the page, not about the style — and a screen reader can act on it.

A column of sections with a rule down the side. The entry for the section being read carries aria-current, so it is the one that takes the brand colour — the stylesheet cannot know which section is on screen, so the page says.

Props

variantenum = line | plainlineWhether a rule runs down the side of the column. The rule is the base class on its own; the plain column adds um-anchor--plain.
labelstringAnchorThe accessible name of the nav element. Every anchor on a page needs its own, or the screen reader announces them all as the same thing.

Slots

NameDescription
defaultThe entries. Each one is an <a> to the fragment of a section; the one for the section being read carries aria-current="location".

Accessibility

Role: navigation

Keyboard: Tab Enter

The column is a <nav> with an aria-label, so a screen reader can jump past it and knows what it navigates, and an <ul>, so the entries are announced as a list and the reader hears how many there are. The entries are links to fragments, so they are in the tab order and can be followed with Enter. The entry for the section being read carries aria-current="location" — the value that means "this is where you are inside a set of things" — and it is the only one that takes the brand colour. No stylesheet can work out which section is on screen, so the host marks it; that is the one thing an anchor needs the page to know.
