Breadcrumb 面包屑

The path to the page you are on, as a list of links. The separators between the steps are drawn by the stylesheet, not written into the markup as characters.

nav, ol, li, a navigation since 1.1.0

The separator is drawn from two borders rather than written as a character. A text separator has to be typed into every markup — `›`, `/` or `»` — and the choice then sits in the document instead of in the theme, where the line weight and the colour are decided. Drawing it means the chevron takes the theme's border colour, and the same stylesheet can offer a second separator without a second character.

Examples

Basic · 基础用法
The path from the root to the page you are on. Only the steps after the first carry a separator, and the last one is not a link.
  1. Home
  2. Library
  3. Annual report 
<nav class="um-breadcrumb" aria-label="Breadcrumb">
  <ol class="um-breadcrumb__list">
    <li class="um-breadcrumb__item">
      <a class="um-breadcrumb__link" href="#">Home</a>
    </li>
    <li class="um-breadcrumb__item">
      <span class="um-breadcrumb__separator" aria-hidden="true"></span>
      <a class="um-breadcrumb__link" href="#">Library</a>
    </li>
    <li class="um-breadcrumb__item">
      <span class="um-breadcrumb__separator" aria-hidden="true"></span>
      <span class="um-breadcrumb__link" aria-current="page">Annual report</span>
    </li>
  </ol>
</nav>
Slash separator · 斜线分隔符
The slash variant draws one line instead of a chevron. It is still a shape: the line takes the theme's border colour and its weight.
  1. Orders
  2. 2026
  3. March 
<nav class="um-breadcrumb um-breadcrumb--slash" aria-label="Breadcrumb">
  <ol class="um-breadcrumb__list">
    <li class="um-breadcrumb__item">
      <a class="um-breadcrumb__link" href="#">Orders</a>
    </li>
    <li class="um-breadcrumb__item">
      <span class="um-breadcrumb__separator" aria-hidden="true"></span>
      <a class="um-breadcrumb__link" href="#">2026</a>
    </li>
    <li class="um-breadcrumb__item">
      <span class="um-breadcrumb__separator" aria-hidden="true"></span>
      <span class="um-breadcrumb__link" aria-current="page">March</span>
    </li>
  </ol>
</nav>

Props

NameTypeDefaultDescription
separatorenum = chevron | slashchevronThe mark between the steps. The chevron is the base class on its own; the slash adds um-breadcrumb--slash.
labelstringBreadcrumbThe accessible name of the nav element. Every breadcrumb on a page needs its own, or the screen reader announces them all as the same thing.

Slots

NameDescription
defaultThe steps of the trail. Each one is an <a> for a step the reader can go back to and a <span> for the page the reader is on; the wrapper writes the separators between them.

Accessibility

Role: navigation

Keyboard: Tab

The trail is a <nav> with an aria-label, so a screen reader can jump past it, and an <ol>, so the steps are announced in order. The last step carries aria-current="page" and is a <span>: it is where the reader already is, so making it a link would offer a trip back to the current page. The separators are empty elements with aria-hidden, because a chevron is a shape and has nothing to say.
