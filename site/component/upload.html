Upload 上传

A file input and the list of the files that were chosen. The input is a real one, so the browser's own dialog opens and the files are chosen with the browser's own picker.

input, label, ul form since 1.1.0

The input is hidden rather than removed, so it stays in the tab order and stays a file chooser to a screen reader; the button beside it is what the pointer reaches and what the focus ring lands on. The list of chosen files is written into the markup, because a library with no JavaScript cannot read the input's own file list — the server that received the upload writes the names back. The status colour is a text role, not a fill colour, so it is measured to read on the row it sits in.

Examples

List · 列表
The trigger and the chosen files below it, one row per file. The names are authored in the markup, so they can be written by the server that received the upload.

Props

NameTypeDefaultDescription
multiplebooleanfalseLets more than one file be chosen at a time. It is the native multiple attribute.
acceptstring—Which file types the picker offers. It is the native accept attribute, so the browser filters the list.
disabledbooleanfalseMakes the upload inert. It uses the real disabled attribute, so it leaves the tab order.
namestring—The name the chosen files are submitted under. It is the native name attribute.
layoutenum = list | textlistHow the chosen files are shown. The list layout is the base class on its own; the text layout adds um-upload--text.
sizeenum = sm | md | lgmdThe size of the trigger and of the file names.
statusenum = default | uploading | done | errordefaultWhere one file has got to. It is a class on the item: no class is the waiting state, and the other three are um-upload__item--uploading, um-upload__item--done and um-upload__item--error.
show-file-listbooleantrueWhether the chosen files are shown under the trigger. The list is there unless the host says otherwise.

Slots

NameDescription
triggerThe text on the trigger. The button is drawn, so a trigger with no text needs an accessible name of its own.
defaultThe text on the trigger. It is the name Element Plus gives the same content.
listThe chosen files, as a list of items.
tipThe line of help under the list of files.

Events

NameDescription
changeFires when files are chosen. It is the browser's own event on the input — the library installs no listener, and it cannot read the chosen files without one.

Accessibility

Role: button

Keyboard: Tab Enter Space

The control is a real <input type="file"> inside a <label>, so the browser's own dialog opens and the file list is the browser's own. The input is hidden visually rather than removed from the accessibility tree, so it keeps its place in the tab order and announces itself as a file chooser. The drawn button carries no text of its own, so the label around it needs an accessible name. The file names in the list are authored in the markup, because a library with no JavaScript cannot read the input's own file list.
