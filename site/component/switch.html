Switch 开关

A binary setting that takes effect the moment it is flipped. The visible switch is drawn by the library; the control underneath it is a real checkbox.

input form since 1.1.0

The track and the thumb are two nested spans, and the thumb moves with a transform rather than a position, so flipping the switch never moves anything around it. The disabled state dims the track with opacity and takes the derived disabled text colour for the label: a track has no text of its own, so only the shape can be dimmed.

Examples

States · 状态
On, off and locked. The state is the input's own checked attribute, so the markup a browser reads is the same one the stylesheet reads.
<label class="um-switch">
  <input class="um-switch__input" type="checkbox" checked />
  <span class="um-switch__track"><span class="um-switch__thumb"></span></span>
  <span class="um-switch__label">Notifications</span>
</label>
<label class="um-switch">
  <input class="um-switch__input" type="checkbox" />
  <span class="um-switch__track"><span class="um-switch__thumb"></span></span>
  <span class="um-switch__label">Digest</span>
</label>
<label class="um-switch">
  <input class="um-switch__input" type="checkbox" disabled />
  <span class="um-switch__track"><span class="um-switch__thumb"></span></span>
  <span class="um-switch__label">Locked</span>
</label>
Without visible text · 没有可见文字
The label element can be left out, but then the switch has no visible name and needs one for a screen reader. Put it on the input.
<label class="um-switch">
  <input class="um-switch__input" type="checkbox" aria-label="Show the sidebar" />
  <span class="um-switch__track"><span class="um-switch__thumb"></span></span>
</label>

Accessibility

Role: checkbox

Keyboard: Tab Space

The switch is a real <input type="checkbox"> inside a <label>, and the drawn parts are spans. The checked state is the browser's :checked, so the switch submits with the form, is announced as a checkbox and needs no JavaScript. The input is hidden visually rather than removed from the accessibility tree, so it keeps its place in the tab order and its label.
