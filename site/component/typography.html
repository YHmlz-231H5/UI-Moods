Typography 文字排版

The set of text styles a page is written in: a title, a subtitle, a paragraph, supporting text, a link and a quote. The library paints the sizes, the colours and the leading; the words and the heading levels are the host's.

div, h1, h2, p, span, a, blockquote basic since 1.1.0

The variant colours the text and nothing else — the title and the subtitle keep the heading colours, because a heading that changed colour with the paragraph would stop being a heading. And the variant takes the text roles rather than the fill roles: the brand colour is made to be a fill, and a fill colour used as writing can sit under 4.5:1 on a page.

Examples

The set · 整套
Every part of the set in one block: the title, the subtitle, the paragraph, the supporting text, the small text, a link and a quote.

Deployment runbook

Nightly, 02:00 to 02:30

Six replicas are moved to the new build one at a time. Each step waits for a health check before the next one starts, so a failure stops the run where it happened rather than halfway through.

The run takes about four minutes when nothing goes wrong.

Last run: 02:11, no differences

The whole procedure is in the runbook, with the rollback steps at the end.

Move one replica at a time, and read the health check before you move the next.

Accessibility

The library paints the type, and the host supplies the structure: the title and the subtitle are real heading elements, and the level is chosen to fit the page — a title that is not an <h1> is invisible to someone navigating by heading. The quote is a <blockquote>, which is what tells a screen reader that the words are someone else's. The link is a real <a>, so it is in the tab order and it can be opened in a new tab.
