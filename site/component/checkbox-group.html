Checkbox Group 复选框组

A set of checkboxes that share one name and belong to one field. The group is a fieldset, so the browser groups the boxes for the form and for the screen reader.

fieldset, input, label form since 1.1.0

The group owns the row and the text of an option, but not the box: the box and the real input are the checkbox component's own classes, so a tick inside a group is drawn exactly like a tick outside one. The group has no sizes of its own, because the box's size belongs to the box — a group cannot make the control it holds bigger without redrawing it. The selected row is found with :has(), which is the only way CSS can ask an element what its child is doing.

Examples

Stacked · 纵向
One option per row. A ticked option takes the brand colour's soft tint, and the row knows it is ticked because it holds the input.
Delivery 
<fieldset class="um-checkbox-group">
  <legend class="um-checkbox-group__legend">Delivery</legend>
  <div class="um-checkbox-group__options">
    <label class="um-checkbox-group__option">
      <input class="um-checkbox__input" type="checkbox" name="um-checkbox-group-delivery" value="standard" checked />
      <span class="um-checkbox__box"></span>
      <span class="um-checkbox-group__label">Standard</span>
    </label>
    <label class="um-checkbox-group__option">
      <input class="um-checkbox__input" type="checkbox" name="um-checkbox-group-delivery" value="express" />
      <span class="um-checkbox__box"></span>
      <span class="um-checkbox-group__label">Express</span>
    </label>
    <label class="um-checkbox-group__option">
      <input class="um-checkbox__input" type="checkbox" name="um-checkbox-group-delivery" value="pickup" disabled />
      <span class="um-checkbox__box"></span>
      <span class="um-checkbox-group__label">Collect in store</span>
    </label>
  </div>
</fieldset>
Inline · 横向
The options run across the panel and wrap onto the next line. Only the modifier class changes; the markup is the same.

Props

NameTypeDefaultDescription
namestring—The name every option in the group submits under. It is the native name attribute, so the form posts every ticked option as one field.
valuestring—The value one option submits while it is ticked.
checkedbooleanfalseTicks one option. It is the native checked attribute, not a class.
disabledbooleanfalseMakes one option inert. It uses the real disabled attribute, so it leaves the tab order.
directionenum = stacked | inlinestackedWhich way the options run. The stacked run is the base class on its own; the inline run adds um-checkbox-group--inline.
labelstring—The text of the group's legend. A group with no legend still needs an accessible name of its own.

Slots

NameDescription
legendThe legend text, above the options.
optionOne option: the real input, the checkbox component's box and the text.

Events

NameDescription
changeFires when an option is ticked or unticked. It is the browser's own event on the input — the library installs no listener.

Accessibility

Role: group

Keyboard: Tab Space

The group is a real <fieldset> with a real <legend>, so the screen reader announces the group's name before the options and reports how many boxes there are. Every option is a real <input type="checkbox"> inside a <label>, so ticking it is the browser's :checked, the value submits with the form and nothing needs JavaScript. The input is hidden visually rather than removed from the accessibility tree, so it keeps its place in the tab order and its label.
