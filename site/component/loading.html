Loading 加载中

A ring that turns while the library waits for something. The ring is two borders with one side left out, and the turn is a keyframe, so it needs neither a timer nor a script.

span, div feedback since 1.1.0

The ring is two borders with the top side left out, and the gap in the ring is that missing side — so the shape is drawn, not fetched. The keyframe it turns with is the one the loading button already uses, because it is the same ring turning the same way; and it only turns at all when the reader has not asked for less motion, which the library never overrides.

Examples

Spinner · 转轮
The ring on its own. It is a shape the stylesheet draws, so there is no icon to load and nothing to install.
<div class="um-loading um-loading--spinner">
  <span class="um-loading__spinner" aria-hidden="true"></span>
</div>
With text · 带文字
The caption is a separate element, so it can be left out. The gap between the ring and the caption is opened by the modifier.
Loading the last 24 hours 
<div class="um-loading um-loading--text" role="status">
  <span class="um-loading__spinner" aria-hidden="true"></span>
  <span class="um-loading__text">Loading the last 24 hours</span>
</div>
Sizes · 尺寸
Three rings, three spacing steps. The middle one is the base class on its own, because the base class is already the medium size.
<div class="um-loading um-loading--spinner um-loading--small">
  <span class="um-loading__spinner" aria-hidden="true"></span>
</div>
<div class="um-loading um-loading--spinner">
  <span class="um-loading__spinner" aria-hidden="true"></span>
</div>
<div class="um-loading um-loading--spinner um-loading--large">
  <span class="um-loading__spinner" aria-hidden="true"></span>
</div>
Overlay · 整页遮罩
The overlay covers the page with a veil and centres a panel on it. The panel is what carries the message, so the ring on its own stays decorative.
Saving the deployment 
<div class="um-loading um-loading--overlay" role="status">
  <div class="um-loading__panel">
    <span class="um-loading__spinner" aria-hidden="true"></span>
    <span class="um-loading__text">Saving the deployment</span>
  </div>
</div>

Props

NameTypeDefaultDescription
variantenum = spinner | text | overlayspinnerWhich of the three shapes this is. The ring on its own is the base class, so the spinner variant only needs the modifier when the markup wants to say so.
sizeenum = small | medium | largemediumHow big the ring is. The sizes are the theme's own spacing steps, so the ring grows with the mood's rhythm instead of sitting at a fixed size.
textstring—The caption beside the ring. It is the message, so it is written as text in the page and not as an attribute.

Slots

NameDescription
textThe caption beside the ring.

Accessibility

Role: status

The ring is a picture of waiting, not a message: mark it aria-hidden and let the caption carry the words. When the indicator appears without the reader having asked for it, put role="status" on the wrapper so the caption is announced; an indicator that was already on the page when it loaded does not need one. The ring turns only when the reader has not asked for less motion.
