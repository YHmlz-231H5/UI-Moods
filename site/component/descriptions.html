Descriptions 描述列表

The facts about one thing, as label and value pairs. It is a definition list, so a screen reader announces each label before the value it belongs to.

dl, div data since 1.1.0

Two things a class name cannot carry are carried by custom properties instead: `--um-descriptions-columns`, the number of pairs per row, and `--um-descriptions-label-width`, the width of the label column. Both are measurements, and a class is a name rather than a number.

Props

NameTypeDefaultDescription
variantenum = plain | borderedplainWhether the list is framed. The base class is already the plain form.
columnsnumber1How many pairs sit in one row. It is written to the `--um-descriptions-columns` custom property, because a class cannot carry a number.
labelWidthstring6emThe width of the label column, so the values line up under each other. It is written to the `--um-descriptions-label-width` custom property.

Slots

NameDescription
itemOne label and its value.

Accessibility

The list is a real dl, and each pair is a div holding a dt and a dd. A screen reader then reads the label and its value as a term and its definition, and lets the reader step from pair to pair — a grid of divs cannot do that. The div wrapper is part of the HTML standard: a dl may hold div groups.
