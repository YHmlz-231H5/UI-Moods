Button 按钮

An action the user takes. The one component every interface needs, and the one that has to look right in thirty-two different moods.

button form since 1.1.0

The quality hook `.um-button--glow` lives in the shared hooks layer rather than in this component, because it is a mood capability and not a button variant. The loading spinner is painted in the label's own colour — the label colour lives in one variable that both read — so the spinner is always as legible as the label it replaced, on every variant and in every mood.

Examples

Variants · 变体
One variant per action type. The label colour on a filled button is the theme's own on-colour, derived to reach 4.5:1 against that fill.
<button class="um-button um-button--primary">Primary</button>
<button class="um-button um-button--default">Default</button>
<button class="um-button um-button--text">Text</button>
<button class="um-button um-button--success">Success</button>
<button class="um-button um-button--warning">Warning</button>
<button class="um-button um-button--danger">Danger</button>
Sizes · 尺寸
The medium size is the default and needs no modifier class.
<button class="um-button um-button--primary um-button--sm">Small</button>
<button class="um-button um-button--primary">Medium</button>
<button class="um-button um-button--primary um-button--lg">Large</button>
States · 状态
A disabled button paints a flat surface and takes the derived disabled colour, so its label is still measurable. It is not dimmed with opacity, because opacity is not a colour and nothing about it can be checked.
<button class="um-button um-button--primary" disabled>Disabled</button>
<button class="um-button um-button--default" disabled>Disabled</button>
<button class="um-button um-button--primary um-button--loading">Loading</button>

Props

NameTypeDefaultDescription
variantenum = primary | default | text | success | warning | dangerdefaultWhich action this is.
sizeenum = sm | md | lgmdThe control height.
disabledbooleanfalseMakes the button inert.
loadingbooleanfalseShows a spinner and hides the label, keeping the width.
glowbooleanfalseApplies the mood's glow hook. A mood without one shows nothing.
roundbooleanfalseGives the button the pill shape, whatever height it is.
circlebooleanfalseMakes the button a disc: as wide as it is tall.
dashedbooleanfalseDraws the outline as a dashed line.
linkbooleanfalseMakes the button read as a link: no fill, no border, and an underlined label.

Accessibility

Role: button

Keyboard: Enter Space

A real <button> element, so it is focusable, activatable by keyboard and announced correctly. A disabled button uses the real disabled attribute rather than aria-disabled, so it is skipped by the tab order.
