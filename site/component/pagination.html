Pagination 分页

The pages of a long list, with the previous and next arrows at either end and the current page filled in. The arrows are chevrons drawn from two borders.

nav, ul, li, a, button, input navigation since 1.1.0

The arrows are chevrons drawn from two borders, and they take `currentColor`, so an arrow is disabled by the same rule as the label beside it. A text arrow would have to be a character in the markup, and the library would have to choose which one — `‹`, `«` or an image — and the choice would then sit in the document instead of in the theme.

Accessibility

Role: navigation

Keyboard: Tab

The pager is a <nav> with an aria-label, so a screen reader can jump past it. The current page carries aria-current="page", which is what tells the reader where they are without relying on the fill. The two arrows are <button>s rather than links, because an arrow at the end of the run has to be disableable and a link cannot be disabled.
