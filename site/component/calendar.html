Calendar 日历

One month laid out as a seven-column grid. It draws the month and marks the days; which month to show is the host's business, because a grid cannot know which months exist.

div data since 1.1.0

The calendar has no navigation of its own. A month is a grid of days, and a grid cannot know which months exist, so the host owns the month and the host owns the buttons that change it; what the calendar gives the host is a grid it can drop into any panel. The three markers are kept apart on purpose: today is a filled circle with a number on it, so it is a surface with text and takes the brand's on-colour; selected is a ring with nothing on it, so it is a shape and takes the graphic form of the brand colour; disabled is a number that takes the derived disabled colour. The weekday names are written out rather than derived, because a month may start on Monday or on Sunday and a host may name the columns in its own language.

Props

NameTypeDefaultDescription
variantenum = bordered | plainborderedThe shape of the panel. The bordered run is the base class on its own; the plain run adds um-calendar--plain.
sizeenum = sm | md | lgmdThe size of the day numbers and of the cells.
monthstring2026-11The month to draw, written as YYYY-MM. The calendar has no navigation of its own, so the host decides which month this is.
weekdaysstringMon,Tue,Wed,Thu,Fri,Sat,SunThe seven column names, separated by commas. They are written out rather than derived, so a month can start on Monday or on Sunday, and so a host can name the columns in its own language.
todaystring2026-11-28The date that is today, written as YYYY-MM-DD. The day it names takes the today marker.
selectedstring2026-11-20The date the reader has picked, written as YYYY-MM-DD. The day it names takes the selected marker.
model-valuestring—The bound date. It answers to `v-model` as well as to `selected`, and the binding wins when it is there.
disabledstring2026-11-05,2026-11-06The dates that cannot be picked, written as YYYY-MM-DD and separated by commas. The days they name are marked with aria-disabled, so the reader is told they cannot be picked.

Slots

NameDescription
date-cellThe content of one day of the grid. It is written instead of the day number, and it is given the date it belongs to.
headerThe heading of the panel, above the weekday names. It is the caller's, because the month and the way it is named are the caller's too — the grid only draws the days.

Accessibility

Role: grid

The panel is the grid: the weekday names are a row of column headers and the weeks are rows of grid cells, so the browser says which column a day belongs to and a reader can walk the week across. The day numbers are real text, so the grid can be read without seeing it. A day that cannot be picked carries aria-disabled, so the reader is told that day is unavailable; the other two markers are classes and not attributes, so the reader is not told which day is today or which one is selected: the host has to say that in the markup or in the text around the grid.
