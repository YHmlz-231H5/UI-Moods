Table 表格

Rows of records in columns. It is a real table, so the column names travel with the cells and a screen reader can read a row across.

table, thead, tbody, tr, th, td, div data since 1.1.0

The frame belongs to the wrapper and the lines to the cells, so the outside edge is one line everywhere and the inner lines meet it instead of doubling it. The stripe and the header fill are two different fills on purpose: the stripe has to stay behind the text without pulling the eye off it.

Props

NameTypeDefaultDescription
variantenum = striped | bordered—Which extra treatment the table carries. The two modifiers are independent and may be used together.
emptyTextstringNo dataWhat the empty cell says when there are no records.
stripebooleanfalseWhether every other row takes the lighter fill. It adds um-table--striped, the same class the variant prop adds.
borderbooleanfalseWhether a vertical line stands between the columns as well as the horizontal ones. It adds um-table--bordered, the same class the variant prop adds.
sizeenum = sm | md | lgmdHow much room a row takes. The middle size needs no modifier class.
show-headerbooleantrueWhether the row of column names is drawn. Turning it off adds um-table--no-header.
highlight-current-rowbooleanfalseWhether the row the reader is on takes the highlight fill. That row is marked with um-table__row--current.
show-summarybooleanfalseWhether the summary row at the foot of the table is drawn. Turning it off adds um-table--no-summary.
alignenum = start | center | endstartWhere the cells stand in their column. The start is the base class on its own; the centre adds um-table--align-center and the end adds um-table--align-end.
fitbooleanfalseWhether the columns share the width of the frame rather than taking the width their contents ask for. It adds um-table--fit.
typeenum = | selection | index | expand—The extra column the table carries: the tick, the row's number, or the marker that opens a record. The cell is the host's own, and the class says how that column is painted.
default-expand-allbooleanfalseWhether every record's expanded area is drawn, whether the record is marked as open or not. It adds um-table--default-expand-all.
scrollbar-always-onbooleanfalseWhether the frame keeps its scrollbar whether the table needs one or not, so the rows do not move sideways as the table grows. It adds um-table--scrollbar-always-on.

Slots

NameDescription
defaultThe rows of the table. Each one is a row of cells.
headerThe row of column names. Each one is a heading cell with scope="col".
emptyWhat the empty cell says when there are no records. Without it the emptyText prop says it.
appendWhat stands under the last record: a loading row, a load-more button.
summaryWhat the summary row at the foot of the table says: the totals.
expandWhat a record opens up to. It is given the number of the record. The area under a record is not drawn until the record is marked as open, or until the table is told to open them all.

Accessibility

Role: table

A real table with a thead and a tbody, so the column names are announced with every cell and the reader can move across a row. Put scope="col" on the header cells. The wrapper scrolls sideways when the columns are too many to squeeze; a scrollable region has to be reachable by keyboard, so give the wrapper tabindex="0" and a name.
