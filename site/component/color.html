Color 色板

The semantic colours of the mood, drawn as a readable palette. Every cell names the role it shows and the address of the value behind it.

ul, li basic since 1.1.0

The swatch is a solid surface and the name on it is the role's own on-colour, which is the one pairing the contract derives to 4.5:1 against that fill — so the label reads on the colour it names, in every mood, without anybody measuring it twice. The line under the swatch prints the role rather than the resolved value: CSS cannot read a computed colour back out into text, and a hex written into the markup would be a colour that belongs to one mood and to no other.

Examples

The palette · 色板
The five semantic roles of the contract. Under each swatch is the role that carries the colour: a resolved hex cannot be printed without JavaScript, so the palette names the address of the value and the host may write the value it resolved into the cell.

Accessibility

Role: list

The palette is a <ul>, so the reader hears how many colours there are. The name of the role is written on the swatch in the role's own on-colour — the pairing the contract measures — so it reads on the colour it names in every mood, and the colour never has to carry the meaning alone.
