Icon 图标

The handful of marks a page needs most, drawn in CSS out of borders and pseudo-elements. The library ships no icon font, so every glyph here is a shape.

span basic since 1.1.0

The glyphs are drawn, not typed. A character would have to be in the markup, and a font would have to be loaded, and both put the shape of the mark in the document instead of in the theme — where the weight, the colour and the size are decided. Drawn here, the same seven marks work in every mood, and a mark that sits in a button takes the button's own colour.

Examples

The marks · 这些记号
Every mark in the set, each drawn from borders and pseudo-elements. They take the colour of the text they sit in, because an icon that chose its own colour would be a second visual system.

Sizes · 尺寸
The glyph is one em square, so it is as big as the text it sits in. The size changes the type size it is measured against.
<span class="um-icon um-icon--check um-icon--sm" aria-hidden="true"></span>
<span class="um-icon um-icon--check" aria-hidden="true"></span>
<span class="um-icon um-icon--check um-icon--lg" aria-hidden="true"></span>
With a name · 带名字
An icon that carries the message on its own is given a name, and it is announced as an image with that name. An icon beside a word stays hidden, because the word already says it.
Running 
<span class="um-icon um-icon--close" role="img" aria-label="Dismiss"></span>
<span class="um-icon um-icon--dot" aria-hidden="true"></span>
<span>Running</span>

labelstring—The name of the mark, for the case where the icon carries meaning on its own. An icon with a label is announced as an image; an icon without one is hidden from the screen reader.

Accessibility

Role: img

An icon is a shape and says nothing by itself, so it is hidden from the screen reader by default. When it is the only thing in a button, that button needs an accessible name of its own. When the icon is the message — a close mark that stands for “dismiss” — give it a label: the wrapper then exposes it as role="img" with that name, and the shape is announced instead of skipped.
