Container 容器

A fixed width, centred block of content. The width is a step of the type size rather than a number of pixels, so a mood with larger type gets a larger container.

div basic since 1.1.0

The width is written in em, not in pixels: a container is a measure of text, and a measure that does not follow the type size stops being a measure the moment a mood changes its type. The padding is inside the width, so the text a reader reaches is the same distance from the edge at every tier.

Examples

The width tiers · 宽度档
Each tier is a step of the type size, so the container grows with the text instead of staying the same number of pixels in every mood. The medium tier is the default and needs no modifier class.

A narrow column of text, for the side of a page.

The default column. The text stops here, and the rest of the page is left alone.

A wide column, for a page that has to hold a table and the sentence that explains it.

<div class="um-container um-container--sm">
  <p>A narrow column of text, for the side of a page.</p>
</div>
<div class="um-container">
  <p>The default column. The text stops here, and the rest of the page is left alone.</p>
</div>
<div class="um-container um-container--lg">
  <p>A wide column, for a page that has to hold a table and the sentence that explains it.</p>
</div>
Not centred · 不居中
The left variant puts the container against the edge of its parent. A page that is already inside a frame of its own does not want a second one in the middle.

This container is against the left edge of its parent.

<div class="um-container um-container--left">
  <p>This container is against the left edge of its parent.</p>
</div>
Full width · 满宽
The full tier drops the cap altogether. It is still centred — a block that fills its parent has nothing to centre — and it still carries the padding, so the text does not touch the edge of the screen.

This container is as wide as the page it is in.

<div class="um-container um-container--full">
  <p>This container is as wide as the page it is in.</p>
</div>

Accessibility

The container is a div and adds nothing to the accessibility tree: it is a width, not a thing. It draws no frame of its own, so the content inside it is read as it is and the reader is not told about a box that has no name.
