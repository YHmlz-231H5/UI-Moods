Input / Textarea / Select 输入框 / 文本域 / 选择器

The three text controls a form is mostly made of: a single-line input, a multi-line textarea and a native select. One stylesheet gives all three the same border, focus ring and disabled treatment, so a form reads as one form.

input, textarea, select form since 1.1.0

The three controls are three classes, not three variants: um-textarea and um-select carry no modifier, so the family is told apart by the class you write rather than by a modifier you add. The textarea is three control-heights tall and resizes vertically. The select drops the platform arrow and draws its own, because the platform arrow does not follow the theme.

Examples

The three controls · 三种控件
One class each: um-input for a single line, um-textarea for several, um-select for a choice. They are not variants of one another — they are three classes that share one stylesheet.
<input class="um-input" type="text" placeholder="Your name" />
<textarea class="um-textarea" rows="3" placeholder="Description"></textarea>
<select class="um-select">
  <option>Choose an option</option>
  <option>Second</option>
  <option>Third</option>
</select>
States · 状态
A disabled control paints a flat surface and takes the derived disabled text colour rather than being dimmed with opacity, so what is written in it can still be measured.
<input class="um-input" type="text" placeholder="Disabled" disabled />
<textarea class="um-textarea" rows="3" placeholder="Disabled" disabled></textarea>
<select class="um-select" disabled>
  <option>Disabled</option>
</select>

Props

NameTypeDefaultDescription
controlenum = input | textarea | selectinputWhich member of the family this is. Each one is its own class: um-input, um-textarea, um-select.
placeholderstring—The hint text for the input and the textarea. It takes the muted placeholder role, not the body colour.
disabledbooleanfalseMakes the control inert. It uses the real disabled attribute, so it leaves the tab order.
readonlybooleanfalseKeeps the value visible but stops it being edited. The library does not repaint a readonly control — it is not a state it measures.

Events

NameDescription
inputFires on the input and the textarea while the value is typed. It is the browser's own event — the library installs no listener.
changeFires when the value is committed: on blur for the input and the textarea, and when an option is picked for the select.
focusFires when the control takes focus. The stylesheet reacts to :focus, so the brand border and the soft ring appear without a line of script.
blurFires when the control loses focus.

Accessibility

Every control keeps its native element, so the roles, the keyboard behaviour and the form submission all come from the platform: textbox for the input and the textarea, combobox for the select. The select's arrow is drawn with two CSS gradients instead of the native one, because the native arrow ignores the theme; the option list is still the platform's. A disabled control uses the real disabled attribute, so it is skipped by the tab order.
