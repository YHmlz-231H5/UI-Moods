Empty 空状态

What a screen shows when there is nothing to show. It states the fact, and when there is a way out of it, it says what that way is.

div data since 1.1.0

The empty state is text the reader can act on. The library paints the plate, the colour and the spacing; what is missing, and what to do about it, is written by the host.

Examples

Empty · 空状态
The art sits in a round plate the mood paints, so it takes the placeholder colour and never competes with the message.

Classes

ClassMeaning
um-emptyThe base class. Every instance carries it.
um-empty__artArt
um-empty__titleTitle

Slots

NameDescription
artThe illustration. It goes in `.um-empty__art`; a decorative one is hidden from the screen reader.
titleThe headline — what is missing.

Accessibility

The empty state is a message, not a picture: the title is the message and it has to be real text. The art is decoration, so mark it aria-hidden and the screen reader will not read out a stray character. When the empty state appears because the reader changed a filter, wrap it in role="status" so the change is announced; when it was there when the page loaded, it needs no live region.
