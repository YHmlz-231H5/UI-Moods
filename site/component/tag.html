Tag 标签

A label for one piece of data — a category, a state, a filter. The outlined member of the chip family, so it can sit beside a filled badge without either of them winning.

span data since 1.1.0

The tag is the outlined member of the soft-chip family. Its border is a derived brand colour (`color-*-text`) rather than a tint of the fill: a tint would sit at about 1.2:1 against the fill, which reads as a smear rather than an edge. `color-*-text` is guaranteed to read on the page, the overlay and the container, so the outline survives every theme.

Examples

Variants · 变体
The base class on its own is the neutral tag: the theme's default border on the plain surface. The four variants tint the fill and outline it with the derived brand colour.
Draft Primary Success Warning Danger 
<span class="um-tag">Draft</span>
<span class="um-tag um-tag--primary">Primary</span>
<span class="um-tag um-tag--success">Success</span>
<span class="um-tag um-tag--warning">Warning</span>
<span class="um-tag um-tag--danger">Danger</span>
In a line of text · 混在文字里
The tag is inline, so it drops into a sentence the way a word does. Its height comes from the mood, so the line grows a little around it.

Build 214 is passing on all three nodes.

<p>Build 214 is <span class="um-tag um-tag--success">passing</span> on all three nodes.</p>

Accessibility

The tag is text inside a plain <span>: it is read where it sits and it is never focusable. If the tag is meant to be clicked or removed, use a real <button> or <a> and keep the class on it — a clickable span is not focusable and is not announced as a control.
