Dropdown 下拉菜单

A row of actions that stays out of the way until it is wanted. The trigger is a <summary>, so the panel opens and closes with the browser's own disclosure behaviour.

details, summary, button navigation since 1.1.0

The panel is hidden with `display: none` and shown again by `[open]`, rather than left to the browser's rendering of a closed <details>. The browser hides a closed details with a slot, which is not guaranteed to catch a child that has been taken out of the flow — and this panel is absolutely positioned, so it has been. Two lines of CSS buy a guarantee that the closed panel is really gone.

Examples

Basic · 基础用法
A trigger with three actions and a divider. The panel lines up with the left edge of the trigger.
Actions 
<details class="um-dropdown">
  <summary class="um-dropdown__trigger">Actions</summary>
  <div class="um-dropdown__menu">
    <button class="um-dropdown__item" type="button">Rename</button>
    <button class="um-dropdown__item" type="button">Duplicate</button>
    <hr class="um-dropdown__divider" />
    <button class="um-dropdown__item" type="button">Delete</button>
  </div>
</details>
Aligned to the end · 右对齐
The end variant lines the panel up with the right edge of the trigger, which is what a menu on the right edge of a toolbar usually wants.
More 
<details class="um-dropdown um-dropdown--end">
  <summary class="um-dropdown__trigger">More</summary>
  <div class="um-dropdown__menu">
    <button class="um-dropdown__item" type="button">Export</button>
    <button class="um-dropdown__item" type="button">Share</button>
    <hr class="um-dropdown__divider" />
    <button class="um-dropdown__item" type="button">Archive</button>
  </div>
</details>

Accessibility

Role: button

Keyboard: Tab Enter Space Escape

The trigger is a <summary>, so the browser announces it as a disclosure button and says whether the panel is open. The panel is hidden with `display: none` rather than left to the browser's closed-details rendering, because an absolutely positioned child is the one case where the two are not guaranteed to agree. The items are buttons, so they are in the tab order and can be pressed; a menu of links would be a list of <a>s instead.
