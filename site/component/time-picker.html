Time Picker 时间选择器

A field for a time of day. It is a real <input type="time"> inside a box the library draws, so the browser validates the hour, the arrow keys walk the segments and the reader's own clock opens it.

input form since 1.1.0

The picker is the browser's own, and the library does not take it away: hiding the native indicator would remove the only way to open the clock without JavaScript. The drawn clock beside the time is decoration, so it is hidden from the screen reader and the field needs a label of its own. The indicator's colour follows the reader's system rather than the mood, because the contract has no role for "this mood is a dark one" and a wrong colour was not an option.

Examples

Single time · 单个时刻
One time in one field. The clock is the library's own decoration; the button that opens the picker is the browser's, on the other side of the time.
<div class="um-time-picker um-time-picker--single">
  <span class="um-time-picker__icon" aria-hidden="true"></span>
  <input class="um-time-picker__input" type="time" id="um-time-picker-start" name="um-time-picker-start" value="09:30" step="900" />
</div>
Range · 时间区间
Two times in one box, with a rule between them. The markup carries a second input and the separator.
<div class="um-time-picker um-time-picker--range">
  <span class="um-time-picker__icon" aria-hidden="true"></span>
  <input class="um-time-picker__input" type="time" id="um-time-picker-from" name="um-time-picker-from" value="09:00" step="900" />
  <span class="um-time-picker__separator" aria-hidden="true"></span>
  <input class="um-time-picker__input" type="time" name="um-time-picker-to" value="17:30" step="900" aria-label="End of the shift" />
</div>
Out of range · 超出范围
A field with a window the browser enforces. A time outside the window turns the border to the danger colour — but only after the reader has been there, so an empty field is not red on arrival.
<div class="um-time-picker">
  <span class="um-time-picker__icon" aria-hidden="true"></span>
  <input class="um-time-picker__input" type="time" id="um-time-picker-window" name="um-time-picker-window" value="18:30" min="09:00" max="17:00" step="900" required />
</div>

Props

NameTypeDefaultDescription
valuestring—The time in the field. It is the input's own value, in the browser's own format — a class cannot carry a time.
minstring—The earliest time the field accepts. It is the input's own min attribute, so the browser enforces it and marks the field out of range when it is not met.
maxstring—The latest time the field accepts. It is the input's own max attribute.
stepnumber900How fine the time is, in seconds. It is the input's own step attribute, so the arrow keys move by it too.
requiredbooleanfalseMakes the time necessary. It is the native required attribute, so the browser asks for it.
disabledbooleanfalseMakes the field inert. It uses the real disabled attribute, so it leaves the tab order.
typeenum = single | rangesingleWhether the field holds one time or two. The single field is the base class on its own; the range field adds um-time-picker--range.
sizeenum = sm | md | lgmdThe height of the field.
model-valuestring—The time in the field, bound with v-model in Vue. Leave it out and the `value` prop is the time; bind it and the field answers to the binding.

Slots

NameDescription
iconThe clock face. It is decorative and drawn by the library, so it takes no text of its own.

Events

NameDescription
changeFires when the time changes. It is the browser's own event on the input — the library installs no listener.
inputFires on every keystroke in the field. It is the browser's own event on the input.
update:modelValueFires when the value changes, carrying the new value. This is the event `v-model` listens to.

Accessibility

Role: textbox

Keyboard: Tab Arrow keys Enter

The field is a real <input type="time">, so the browser validates it, the arrow keys walk through the hours and the minutes and a screen reader announces it as a time field with its own segments. Give it a real <label for> or an aria-label — the drawn clock is decorative and carries no text. The button that opens the picker is the browser's own and is left where the browser puts it; the library's clock is decoration beside it, not a second control.
