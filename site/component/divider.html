Divider 分割线

A rule between two things. It can carry a label in the middle, drop the rules and keep the label, or stand up as a vertical rule.

div other since 1.1.0

The base divider draws its two rules with pseudo-elements, so the label in the middle is ordinary content — the divider never positions it with anything else. The vertical form hides those pseudo-elements and paints its own rule instead.

Examples

Horizontal · 横线
Two rules with the label between them. The label is the divider's content, so it is read as part of the page.
or
<div class="um-divider">or</div>
Plain · 纯文字
The plain variant drops both rules and leaves the label alone, for the case where the words should not be interrupted.
or
<div class="um-divider um-divider--plain">or</div>
Vertical · 竖线
The vertical rule is as wide as the mood's border and stretches to the height of the row around it, so it needs a flex parent.
Left
Right 
<div style="display:flex;align-items:stretch;gap:var(--um-space-sm);height:var(--um-height-lg)">
  <span>Left</span>
  <div class="um-divider um-divider--vertical" role="separator" aria-orientation="vertical"></div>
  <span>Right</span>
</div>

Classes

ClassMeaning
um-dividerThe base class. Every instance carries it.
um-divider--plainPlain
um-divider--verticalVertical
um-divider--dashedDashed
um-divider--dottedDotted
.um-divider--content-startContent at the start
.um-divider--content-endContent at the end

Props

NameTypeDefaultDescription
variantenum = plain | vertical | dashed | dotted—Which form of the divider this is. The base class on its own is the horizontal rule with a label in the middle.
border-styleenum = solid | dashed | dottedsolidHow the rule is drawn. The solid rule is the base class on its own; the dashed and the dotted rule add um-divider--dashed and um-divider--dotted, the same classes the variant prop adds.
content-positionenum = start | center | endcenterWhere the label sits on the rule. The middle is the base class on its own; the start and the end add um-divider--content-start and um-divider--content-end.

Slots

NameDescription
defaultThe label that sits on the rule. It is ordinary content, so it is read as part of the page.

Accessibility

Role: separator

The divider is a rule, not a control: nothing on it is focusable and there is nothing to activate. Give it role="separator" so the division is in the accessibility tree, and aria-orientation="vertical" on the vertical form. A separator does not take its name from its content, so the label between the two rules is still read as ordinary text.
