Color Picker Panel 颜色选择面板

The panel a colour picker drops: the colours the host has predefined, a choice among the theme's own named colours, and the hexadecimal value written out. Every swatch is a real radio, so the choice is in the tab order and the browser announces it.

div form since 1.1.0

The colours of the predefine row are data, not theme values: they arrive as a custom property the host sets, so the library itself carries no colour literal — a colour picker without the caller's colours is not a colour picker. The preview chip is the same: the host writes the chosen colour into it, because the library has no colour maths and cannot follow a radio by itself. The theme row is not a colour wheel: it is the theme's own named colours, each painted with its own role in its graphic form, because a swatch's colour is the meaning and no text speaks for it.

Props

NameTypeDefaultDescription
predefinestringBlue #2f6feb,Green #12b886,Amber #f59f00,Red #e03131,Violet #7048e8The colours the panel offers, as a comma-separated list. Each entry is written as "name #rrggbb", so the radio announces the name rather than a string of digits; an entry that is only a colour is announced as it is written.
hueenum = primary | success | warning | danger | infoprimaryWhich of the theme's named colours is chosen. It is the radio that is checked in the theme colour row.
valuestring#2f6febThe colour in the panel, written as a hexadecimal value. It is the text in the value field and the value of the checked swatch.
model-valuestring—The bound colour. It answers to `v-model` as well as to `value`, and the binding wins when it is there.
show-previewbooleantrueWhether the preview chip is shown. Without it the panel has no chip in the value row.
disabledbooleanfalseMakes the panel inert. It uses the real disabled attribute on the radios and on the field, so they leave the tab order and the swatches dim, the way every other disabled control in the library dims.

Accessibility

Role: group

Keyboard: Tab Arrow keys Space

The swatches are real radios, in two groups, so the arrow keys move between the colours of one group and the browser announces the picked one. Every radio names itself, because a swatch is a painted colour and a painted colour carries no text. The hexadecimal field is a real input, so it needs a name of its own. The colour the reader picks is data, not a theme value: nothing in the library can promise that an arbitrary colour reads against an arbitrary surface, which is why the picked swatch is marked by a ring around it rather than by the colour itself.
