Tree Select 树选择器

A tree you pick a leaf from. The branches are disclosures, so the browser opens and closes them, and the leaf that is picked is a real radio, so the browser keeps exactly one of them picked.

div form since 1.1.0

A branch is a disclosure and a leaf is a radio, and the two answer different questions: the disclosure says what is inside, the radio says what is chosen. The circle is drawn by this component rather than borrowed from the radio component, because a class the stylesheet does not declare paints nothing — and the drawn mark is the same one the radio draws, so the two look alike. The arrow takes the room the circle takes on a leaf, so a branch name and a leaf name start at the same place.

One branch, open, with a leaf under it. The leaf that is picked is a real radio, so the pick is the browser's and not a class. The levels are held apart by indentation alone.

Props

NameTypeDefaultDescription
variantenum = plain | linesplainHow the levels are held apart. The plain run is the base class on its own; the guided run adds um-tree-select--lines.
sizeenum = sm | md | lgmdThe size of the text in a row.
namestring—The name every leaf in the tree shares. It is the native name attribute, and it is what makes the leaves a group: the browser keeps exactly one of them picked.
valuestring—The value one leaf submits while it is picked. It is also what the leaf says when the caller gives it no name of its own.
labelstring—The name of the thing the branch holds.
checkedbooleanfalsePicks the leaf. It is the native checked attribute, not a class.
disabledbooleanfalseMakes the leaf inert. It uses the real disabled attribute, so it leaves the tab order.
model-valuestring—The value the picked leaf submits, bound with v-model in Vue. Leave it out and the `value` prop is that value; bind it and the tree answers to the binding.
show-checkboxbooleanfalseDraws a box in front of every leaf instead of a circle, so a leaf reads as something that can be ticked rather than something that can be picked.

Slots

NameDescription
branchThe name of the thing the branch holds.
childrenThe level below: one row per leaf inside this branch.

Events

NameDescription
changeFires when the picked leaf changes. It is the browser's own event on the input — the library installs no listener.
toggleFires when a branch opens or closes. It is the browser's own event on the details — the library installs no listener.
update:modelValueFires when the value changes, carrying the new value. This is the event `v-model` listens to.

Accessibility

Role: group

Keyboard: Tab Enter Space Arrow keys

Every branch is a real <details> and every branch name is a real <summary>, so the browser announces each one as a disclosure button and says whether it is open. The leaves are real radios that share one name, so the browser keeps exactly one of them picked, the arrow keys move the pick inside the group and Tab moves between groups. The input is hidden visually rather than removed from the accessibility tree, so it keeps its place in the tab order and its label. The row knows it is picked because it holds the input: :has() is the only way CSS can ask an element what its child is doing.
