Autocomplete 自动补全

A text field that offers values while the reader types. The suggestions live in a native <datalist>, so the browser filters them, the arrow keys walk them and the popup opens without a line of script.

input form since 1.1.0

The suggestions are a <datalist> and not a disclosure: a <details> panel would let the library paint every row of the list, but it would not filter, it would not follow the caret, and the reader would have to open and close it by hand. The <datalist> gives up the paint of the popup — the frame around it belongs to the reader's system — and buys filtering, the arrow keys and the combobox announcement for nothing. The list is static markup, so what it holds is the host's data and the library never fetches it.

Examples

A field with suggestions · 带建议的字段
The suggestions are a <datalist>, so the browser filters them as the reader types. The field names itself for the reader; the library draws no label of its own.
<div class="um-autocomplete um-autocomplete--bordered">
  <input class="um-autocomplete__input" type="text" id="um-autocomplete-city" name="um-autocomplete-city" list="um-autocomplete-cities" placeholder="Start typing a city" aria-label="City" autocomplete="off" />
  <datalist class="um-autocomplete__list" id="um-autocomplete-cities">
    <option class="um-autocomplete__option" value="Amsterdam"></option>
    <option class="um-autocomplete__option" value="Berlin"></option>
    <option class="um-autocomplete__option" value="Copenhagen"></option>
    <option class="um-autocomplete__option" value="Dublin"></option>
    <option class="um-autocomplete__option" value="Edinburgh"></option>
  </datalist>
</div>

Props

NameTypeDefaultDescription
valuestring—The text in the field. It is the input's own value — a class cannot carry a word.
labelstring—The accessible name of the field. It becomes the input's aria-label, because the library does not draw a label of its own.
placeholderstring—The hint text in the field. It takes the muted placeholder role, not the body colour.
suggestionsstringAmsterdam,Berlin,Copenhagen,Dublin,EdinburghThe suggestions, as one comma-separated string. They are the host's data — the list is fixed markup, not something the library fetches.
requiredbooleanfalseMakes the field necessary. It is the native required attribute, so the browser asks for it.
disabledbooleanfalseMakes the field inert. It uses the real disabled attribute, so it leaves the tab order.
variantenum = bordered | filledborderedThe surface of the field. The bordered run is the base class on its own; the filled run adds um-autocomplete--filled.
sizeenum = sm | md | lgmdThe height of the field.
model-valuestring—The text in the field, bound with v-model in Vue. Leave it out and the `value` prop is the text; bind it and the field answers to the binding.
readonlybooleanfalseKeeps the text visible but stops it being edited. It is the native readonly attribute, so the browser refuses the edit. The library does not repaint a read-only field — it is not a state it measures.

Slots

NameDescription
prefixThe mark in front of the text.

Events

NameDescription
inputFires on every keystroke in the field. It is the browser's own event on the input — the library installs no listener.
changeFires when the value is committed: when the reader leaves the field, or when they pick a suggestion.
focusFires when the field takes focus.
blurFires when the field loses focus.
update:modelValueFires when the value changes, carrying the new value. This is the event `v-model` listens to.

Accessibility

Role: combobox

Keyboard: Tab ArrowDown ArrowUp Enter Escape

The field is a real <input type="text"> with a real <datalist> behind it, so in the browsers that support one the field is announced as a combobox and the arrow keys walk the suggestions. Give the field a real <label for> or an aria-label: the suggestion list is a data source, not a label. The library installs no listener, so it cannot write a chosen suggestion back into the field — the browser does that where it can, and the host does it where it cannot.
