Menu 菜单

A list of places to go, with groups that fold away. The groups are <details> elements, so the browser opens and closes them and keeps them open across a reload.

ul, li, details, summary, a navigation since 1.1.0

The icon slot is deliberately empty. The library ships no icon font and no image, so the slot is a sized empty span the host fills with whatever it already uses — an inline SVG, a sprite, a character. It carries the space either way, so adding a glyph does not move the text.

Props

NameTypeDefaultDescription
directionenum = vertical | horizontalverticalWhich way the entries run. The vertical menu is the base class on its own; the horizontal menu adds um-menu--horizontal.
activestring—Which entry is the current one. It is the um-menu__active class on that entry's item.
modeenum = vertical | horizontalverticalWhich way the entries run. This is Element Plus's name for the `direction` prop; either one of them lays the menu out.
collapsebooleanfalseWhether the menu is a column of glyphs. It adds um-menu--collapse: every entry is narrowed to the icon column and its label is clipped out of it. The library draws no icons of its own, so the glyph in a collapsed entry is the host's.
disabledbooleanfalseWhether the menu is inert. It adds um-menu--disabled: the pointer does not reach the entries and they take the derived disabled colour.
ellipsisbooleanfalseWhether a group title that is too long is cut with an ellipsis instead of wrapping. It adds um-menu--ellipsis.
popper-effectenum = light | darklightHow the floating submenu is filled. The light run is the base class on its own; the dark run fills the panel with the mood's strong text colour and adds um-menu--popper-dark.

Slots

NameDescription
iconThe glyph in front of an entry. It goes inside the icon slot, which is empty by default.
defaultThe entries of the menu.
titleThe title of the group. It goes in the group's summary, beside the marker.

Events

NameDescription
openFires when a group opens. It is the browser's own toggle event on the group's <details>, caught on the way down.
closeFires when a group closes. It is the browser's own toggle event on the group's <details>, caught on the way down.
selectFires when an entry is pressed. It carries the text of the entry and the event itself.

Accessibility

Role: list

Keyboard: Tab Enter Space

The menu is a <ul> of <li>s, so the entries are announced as a list and the reader hears how many there are. A group is a <details> with a <summary>, so it opens with Enter or Space and the browser says whether it is open or closed. The icon slot is aria-hidden: it is empty in the markup, and whatever the host puts there is decoration beside a label that is already read out.
