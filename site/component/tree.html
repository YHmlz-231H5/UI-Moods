Tree 树

Things inside things. Every branch is a disclosure, so the browser opens and closes it and the state survives a reload.

div data since 1.1.0

A branch is a disclosure and not a menu: the browser owns the open state, so the branch stays open across a reload and the reader gets the collapsed and expanded announcement for free. The level below is indented rather than drawn over the label, so a long name has the whole width of the level to itself. The arrow is drawn from two borders, so it takes the label's own colour and a branch that is dimmed dims with it.

Accessibility

Role: group

Keyboard: Tab Enter Space

Every branch is a real <details> and every label is a real <summary>, so the browser announces each label as a disclosure button and says whether its branch is open. The keyboard is the browser's own: Tab reaches the labels, Enter or Space opens the branch. The arrow is drawn from borders, so it carries no text — the state is announced by the browser, not by the mark. The tree role is not used on purpose: it promises tree items and arrow-key navigation, and a tree of disclosures does not deliver either.
