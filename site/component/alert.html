Alert 警告

A message that stays in the page and says what the reader has to know: the run failed, the quota is nearly gone, the sync is through. The variant colours the border and the mark, not the text.

div feedback since 1.1.0

The variant colours the border, the mark chip and the icon, and nothing else. The body text stays in the mood's regular text colour, so an alert never changes the reading colour of the paragraph it interrupts. The icon takes the variant's graphic colour rather than its fill colour, because it is a shape that carries its meaning on its own.

Props

NameTypeDefaultDescription
variantenum = primary | success | warning | danger | info—Which kind of message this is.
centerbooleanfalsePuts the body in the middle of the panel, so the alert reads as a line rather than as a paragraph against the edge.
closablebooleanfalsePuts a close button at the end of the panel. The button is a real one, so it is in the tab order and it is pressed with the keyboard.
show-iconbooleanfalsePuts the drawn mark in front of the body, so the kind of message is readable before the words are.

Slots

NameDescription
defaultThe body of the alert: the text under the title.
titleThe title of the alert.
markThe chip in front of the body.

Events

NameDescription
closeFires when the reader presses the close button. The library installs no listener — the host decides what closing means, and the alert itself stays on the page until the host takes it away.

Accessibility

The alert is a plain container, so it carries no role of its own. When it appears without the user asking for it, give it role="alert" (urgent) or role="status" (informational) so it is announced; an alert that was already on the page when it loaded does not need one. The mark chip is a label, so hide it with aria-hidden when the title already says the same thing.
