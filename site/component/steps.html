Steps 步骤条

The order of a job, one step per entry, with the step you are on picked out and the steps already done marked as finished.

ol, li, span navigation since 1.1.0

The status is a class on the step rather than a variant on the whole component, because a run of steps is a mix of states: one step done, the next one running, the rest waiting. A component-level variant would paint every step the same. The line is kept neutral in every state, so the only coloured thing on the bar is the step it belongs to.

Examples

Horizontal · 横向
The usual run: one step is done, one is being worked on, one is waiting. The status is a class on the item, so the three can be different.

  2. 2 Review Someone checks the details.
  3. 3 Ship The parcel leaves the warehouse.

Props

NameTypeDefaultDescription
directionenum = horizontal | verticalhorizontalWhich way the steps run. The horizontal run is the base class on its own; the vertical run adds um-steps--vertical.
statusenum = default | active | success | error | dangerdefaultWhere the step stands. It is a class on the item: no class is the waiting state, and the other four are um-steps__item--active, um-steps__item--success, um-steps__item--error and um-steps__item--danger.
process-statusenum = default | active | success | error | dangerdefaultWhere the step that is being worked on stands. This is Element Plus's name for the `status` prop; either one of them says it.
activenumber0Which step is being worked on, counted from one. That step carries the running state; zero leaves the states where the markup put them.
align-centerbooleanfalseWhether the title and the description stand in the middle of the step rather than at its start. It adds um-steps--align-center.
simplebooleanfalseWhether the run is the simple one: the titles stand in a row and the descriptions and the line are not drawn. It adds um-steps--simple.

Slots

NameDescription
iconThe number or mark in the round slot. It is text in the markup, so it can be a number, a word or a tick.
defaultThe steps themselves. Each one keeps the status class it was written with.
titleThe title of the step.
descriptionThe line under the title that says what the step is.

Accessibility

Role: list

The steps are an <ol>, so they are announced in order and the reader hears how many there are. The status is a class on the item and not an attribute, which means the state is not announced — a finished step sounds like a waiting one. The number in the icon is the text the screen reader reads, so it has to say where the step stands, or the class has to be carried into the markup as well.
