Scrollbar 滚动条

A box that scrolls, with a scrollbar drawn in the mood's own colours instead of the platform's. The bar is a shape and a line, not a widget: there is no thumb to drag with a mouse, only a box that scrolls.

div basic since 1.1.0

The frame paints the line and clips the corners; it paints no surface, because a fill here would put the scrollbar's own track on top of a second layer of the same translucent colour, and the colour under the bar would then be one that no role names. The scrollbar is drawn twice over, once for the WebKit engines with ::-webkit-scrollbar and once for Firefox with scrollbar-color, because the two engines do not share a way of painting it. The thickness is a component constant rather than a mood's spacing step: a scrollbar that is 28 pixels wide because the theme's section gap is 28 pixels is not a scrollbar.

A list in a box that is shorter than the list. The track is painted, so the bar sits in a channel of its own. The box is given a height, because a box that is not given one never scrolls.

Props

NameTypeDefaultDescription

heightstring—How tall the scrolling box is. The library cannot guess it: a box that is not given a height never scrolls, because its content is what gives it one.

Accessibility

Role: group

Keyboard: Tab Arrow keys Page Up Page Down Home End

The scrolling box is a real element with overflow on it and a tabindex, so it can be reached with Tab and scrolled with the arrow keys, the page keys and Home and End — the browser's own scrolling, not a script. The scrollbar the browser draws on top of that is replaced by the ::-webkit-scrollbar rules and by scrollbar-color, and neither of those adds anything to the accessibility tree: what a reader hears is the scrollable region and its content, which is the browser's announcement and not the component's. The thumb carries no text, because the position it shows is a picture of a position the browser already knows.
