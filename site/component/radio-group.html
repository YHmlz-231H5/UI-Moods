Radio Group 单选框组

A set of radios that share one name and belong to one field. The group is a fieldset, so the browser groups the circles for the form and for the screen reader.

fieldset, input, label form since 1.1.0

The group owns the row and the text of an option, but not the circle: the circle and the real input are the radio component's own classes, so a picked option is drawn exactly like a lone radio. The group has no sizes of its own, because the circle's size belongs to the circle — a group cannot make the control it holds bigger without redrawing it. The selected row is found with :has(), which is the only way CSS can ask an element what its child is doing.

Examples

Stacked · 纵向
One option per row. The picked option takes the brand colour's soft tint, and the row knows it is picked because it holds the input.
Plan 
<fieldset class="um-radio-group">
  <legend class="um-radio-group__legend">Plan</legend>
  <div class="um-radio-group__options">
    <label class="um-radio-group__option">
      <input class="um-radio__input" type="radio" name="um-radio-group-plan" value="monthly" checked />
      <span class="um-radio__dot"></span>
      <span class="um-radio-group__label">Monthly</span>
    </label>
    <label class="um-radio-group__option">
      <input class="um-radio__input" type="radio" name="um-radio-group-plan" value="yearly" />
      <span class="um-radio__dot"></span>
      <span class="um-radio-group__label">Yearly</span>
    </label>
    <label class="um-radio-group__option">
      <input class="um-radio__input" type="radio" name="um-radio-group-plan" value="lifetime" disabled />
      <span class="um-radio__dot"></span>
      <span class="um-radio-group__label">Lifetime</span>
    </label>
  </div>
</fieldset>

The options run across the panel and wrap onto the next line. Only the modifier class changes; the markup is the same.

Props

NameTypeDefaultDescription
namestring—The name every option in the group shares. It is the native name attribute, and it is what makes the group a group: the browser keeps exactly one of the options picked.
valuestring—The value one option submits while it is picked.
checkedbooleanfalsePicks one option. It is the native checked attribute, not a class.
disabledbooleanfalseMakes one option inert. It uses the real disabled attribute, so it leaves the tab order.
directionenum = stacked | inlinestackedWhich way the options run. The stacked run is the base class on its own; the inline run adds um-radio-group--inline.
labelstring—The text of the group's legend. A group with no legend still needs an accessible name of its own.

Slots

NameDescription
legendThe legend text, above the options.
optionOne option: the real input, the radio component's circle and the text.

Events

NameDescription
changeFires when the selection moves to an option. It is the browser's own event on the input — the library installs no listener.

Accessibility

Role: radiogroup

Keyboard: Tab Space Arrow keys

The group is a real <fieldset> with a real <legend>, so the screen reader announces the group's name before the options and reports how many there are. Every option is a real <input type="radio"> inside a <label>, so the browser keeps exactly one of them picked, the arrow keys move the selection inside the group and Tab moves between groups. The input is hidden visually rather than removed from the accessibility tree, so it keeps its place in the tab order and its label.
