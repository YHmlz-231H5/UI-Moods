Popconfirm 气泡确认

A bubble that asks before it acts. It hangs off a trigger, and it holds a question and the two real buttons that answer it: confirm and cancel.

div feedback since 1.1.0

The bubble is hidden with `display: none` and shown again by the ticked checkbox, rather than by opacity or by visibility: a bubble that is merely transparent is still in the tab order, and its two buttons would still be reachable while it is not there. The arrow is a square turned on its corner, and the two edges that form the point carry the bubble's border colour, so the border line stops at the arrow and picks up again on the other side of it.

Examples

Basic · 基础用法
A trigger and a bubble. The checkbox is invisible and one pixel wide; the label is what the reader sees and clicks.
Delete node-07 and everything on it? This cannot be undone.
<div class="um-popconfirm">
  <input class="um-popconfirm__toggle" type="checkbox" id="popconfirm-basic">
  <label class="um-popconfirm__trigger" for="popconfirm-basic">Delete node</label>
  <div class="um-popconfirm__panel" role="dialog" aria-label="Delete node">
    <span class="um-popconfirm__arrow" aria-hidden="true"></span>
    <div class="um-popconfirm__message">Delete node-07 and everything on it? This cannot be undone.</div>
    <div class="um-popconfirm__actions">
      <button type="button" class="um-popconfirm__cancel">Cancel</button>
      <button type="button" class="um-popconfirm__confirm">Delete</button>
    </div>
  </div>
</div>

Accessibility

Role: dialog

Keyboard: Tab Space

The open state is a real checkbox, so the browser owns it: the label ticks the box, and ticking the box again closes the bubble. The checkbox is the control that takes the focus, so the focus ring is drawn around the trigger it belongs to. The bubble is not modal: it does not trap the focus, and Escape does not close it — a CSS-only library has no key handling to add — so the reader closes it with the same trigger they opened it with. The two answers are real buttons, so both are in the tab order and both can be pressed with the keyboard.
