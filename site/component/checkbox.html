Checkbox 复选框

A box that either is ticked or is not, for choosing one or many things out of a list. The tick is a shape drawn in CSS, not a character.

input form since 1.1.0

The tick is drawn with two borders — a rotated box with only its right and bottom edges — so it is a shape and not a glyph: no icon font, no emoji, and it scales with the box it sits in. The indeterminate state replaces it with a single horizontal border. Both are the same pseudo-element, so there is only one thing to animate.

Examples

States · 状态
Ticked, unticked and locked. The state is the input's own checked attribute, so the markup a browser reads is the same one the stylesheet reads.
<label class="um-checkbox">
  <input class="um-checkbox__input" type="checkbox" checked />
  <span class="um-checkbox__box"></span>
  <span class="um-checkbox__label">Selected</span>
</label>
<label class="um-checkbox">
  <input class="um-checkbox__input" type="checkbox" />
  <span class="um-checkbox__box"></span>
  <span class="um-checkbox__label">Unselected</span>
</label>
<label class="um-checkbox">
  <input class="um-checkbox__input" type="checkbox" disabled />
  <span class="um-checkbox__box"></span>
  <span class="um-checkbox__label">Locked</span>
</label>
Indeterminate · 半选
The dash is the state a parent checkbox takes when only some of its children are ticked. The browser has no attribute for it, so the host sets input.indeterminate = true — this is the one place the library needs a line of JavaScript.
<label class="um-checkbox">
  <input class="um-checkbox__input" type="checkbox" id="um-checkbox-indeterminate" />
  <span class="um-checkbox__box"></span>
  <span class="um-checkbox__label">Some children only</span>
</label>

Accessibility

Role: checkbox

Keyboard: Tab Space

The box is a real <input type="checkbox"> inside a <label>, and the drawn parts are spans. Ticking it is the browser's :checked, so the value submits with the form and the state is announced without JavaScript. The input is hidden visually rather than removed from the accessibility tree, so it keeps its place in the tab order and its label.
