Input Tag 标签输入

A field that holds the tags already chosen, and an empty place to type the next one. Removing a tag needs a script; the shapes of the tag and of its remove button do not.

div form since 1.1.0

Adding a tag and taking one away both need a script, so this component is only the two shapes: the tag and its remove button. The field paints the surface and the input inside it paints none — two translucent layers would be a colour no role names. The variant tints the tags of the whole field rather than of one tag, because in CSS the modifier class sits on the root; a per-tag tone needs the host to write the tag's own class.

Accessibility

Keyboard: Tab Space

The empty part of the field is a real text input, so the keyboard and the autofill behave the way the reader expects. Each remove button is a real button with its own accessible name — "Remove Frontend", not "Remove" — because a reader who hears ten of them in a row needs to know which is which. Give the input an accessible name: an aria-label, or a visible label above the field.
