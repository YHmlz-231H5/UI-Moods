Config Provider 全局配置

Element Plus's config provider is a Vue context: it hands the global size, the z-index, the locale and the namespace down to everything beneath it. A CSS-only library has no context to hand anything down, so this one is an attribute contract instead — a wrapper element carrying data-um-size and data-um-radius, and the library's own CSS answering to them. It sets the density and the radius mode of its subtree, and it says plainly that it cannot do the rest: there is no locale for it to set and no z-index for it to hand out.

div basic since 1.1.0

The density is collapsed onto a rung the provider does not itself override. A custom property cannot be shrunk by re-declaring it in terms of itself — that is a cycle, and the browser throws the value away — so the small rule points the two rungs above it at the small one and leaves the small one alone, and the large rule walks the chain upwards and leaves the large one alone. The circle radius is left alone for the same reason a circle is round in every mood, and the pill radius is left alone because a pill is a shape the host asked for rather than a box. The provider does not pretend to be a context: it cannot set a locale, it has no namespace to prepend, and there is no z-index for it to hand out.

Density · 密度
Three providers, each with a button, a tag and a field in it. The control scale has collapsed onto a different rung in each one, so the button, the field and the type around them are all smaller or larger. The provider that says md is the default, and it is the one the page would have looked like anyway.

Radius mode · 圆角模式

Props

NameTypeDefaultDescription
sizeenum = sm | md | lgmdThe density of the subtree. The whole control scale collapses onto that rung — the heights of the controls and the sizes of the type inside the provider. md is the default, and it changes nothing.
radiusenum = soft | squaresoftThe radius mode of the subtree. square collapses the box radii onto a flat edge; soft is the default, and it changes nothing.

Accessibility

The provider carries no role of its own: it is a plain wrapper, and the elements inside it keep the roles they already had. The density is a visual change, and it changes nothing an assistive technology reads — the same sentence is announced in the same place whether the controls around it are small or large. A smaller control is still a control, and the focus ring around it is still the theme's own.
