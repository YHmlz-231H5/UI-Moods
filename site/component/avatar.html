Avatar 头像

A small picture of a person. It takes a photo, a pair of initials or an icon, and it keeps the shape of whichever mood it is in.

span, img data since 1.1.0

The library cannot fall back on its own — no script may run — so the host decides which of the three forms is written: the image, the initials or the icon. A CSS-only fallback would need to know whether the picture loaded, and that is exactly the kind of thing the browser will not tell it.

Examples

Sizes · 尺寸
Four sizes, each one a step of the mood's own control height, so an avatar in a list of controls lines up with them.
ZM ZM ZM ZM 
<span class="um-avatar um-avatar--sm">ZM</span>
<span class="um-avatar">ZM</span>
<span class="um-avatar um-avatar--lg">ZM</span>
<span class="um-avatar um-avatar--xl">ZM</span>
Shapes · 形状
The round one is the base class. The square one takes the mood's own corner radius rather than a fixed one.
ZM ZM 
<span class="um-avatar um-avatar--circle">ZM</span>
<span class="um-avatar um-avatar--square">ZM</span>
A photo · 照片
The photo is the host's own: an img element with a src the host chooses. This example points at an empty placeholder, so the page asks for nothing and the avatar's own surface shows through.
<span class="um-avatar um-avatar--lg">
  <img class="um-avatar__image" src="data:image/svg+xml,%3Csvg xmlns='http://www.w3.org/2000/svg' viewBox='0 0 32 32'%3E%3C/svg%3E" alt="Zhao Ming">
</span>
An icon · 图标
The icon slot is empty and takes an SVG from the host. The SVG inherits the colour of the slot, so it follows the mood.
<span class="um-avatar um-avatar--lg">
  <span class="um-avatar__icon" aria-hidden="true"><svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.7" stroke-linecap="round" stroke-linejoin="round"><path d="M20 21v-2a4 4 0 0 0-4-4H8a4 4 0 0 0-4 4v2"></path><circle cx="12" cy="7" r="4"></circle></svg></span>
</span>

Props

NameTypeDefaultDescription
variantenum = circle | squarecircleThe shape of the avatar. The base class is already the round one.
sizeenum = sm | md | lg | xlmdThe width and height of the box, and the size of the initials in it.
altstring—The alternative text of the photo. Leave it empty when the name is already written next to the avatar.

Slots

NameDescription
imageThe photo, as an img element.
iconAn icon, as an SVG. The slot itself is empty.

Accessibility

The avatar is usually next to the name, so the photo is often decoration: give the img an empty alt when the name is already there, and the person's name when it is not. The initials are read as the characters they are, so two letters read as two letters.
