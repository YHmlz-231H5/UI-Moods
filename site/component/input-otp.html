Input OTP 验证码输入

A row of one-character fields for a code the reader has been sent. Each box is a real input that holds one character, so the browser's own keyboard, autofill and password manager all still apply to it.

div form since 1.1.0

The boxes are one-character inputs rather than one input with the characters drawn inside it, because a real input keeps the keyboard, the autofill and the password manager — and because a reader who cannot see well may well widen the field to read it. The price is that the caret does not walk from one box to the next on its own: the library has no script, so the host moves it, and the reader can always Tab through the boxes in the meantime.

Examples

Six boxes · 六个格子
Six single-character fields. The first one asks the browser for the one-time-code autofill, so a code that arrived by message can land in it.
<div class="um-input-otp um-input-otp--boxed" role="group" aria-label="Verification code">
  <input class="um-input-otp__field" type="text" inputmode="numeric" maxlength="1" autocomplete="one-time-code" aria-label="Digit 1" />
  <input class="um-input-otp__field" type="text" inputmode="numeric" maxlength="1" autocomplete="off" aria-label="Digit 2" />
  <input class="um-input-otp__field" type="text" inputmode="numeric" maxlength="1" autocomplete="off" aria-label="Digit 3" />
  <input class="um-input-otp__field" type="text" inputmode="numeric" maxlength="1" autocomplete="off" aria-label="Digit 4" />
  <input class="um-input-otp__field" type="text" inputmode="numeric" maxlength="1" autocomplete="off" aria-label="Digit 5" />
  <input class="um-input-otp__field" type="text" inputmode="numeric" maxlength="1" autocomplete="off" aria-label="Digit 6" />
</div>

A disabled row. Every box leaves the tab order, and what was typed stays on screen so the reader can still read it.

Props

NameTypeDefaultDescription
valuestring—The code, as one string. Each character goes into the box at that position; a class cannot carry a code.
lengthnumber6How many boxes there are. It is the host's number of characters, not something the class can say.
maskedbooleanfalseHides what is typed, the way a password field does. It is the input's own type, so the password manager and the reader's own setting still apply.
labelstringOne-time codeThe accessible name of the row. It becomes the group's aria-label, because the boxes are named by their position and the row itself needs a name of its own.
disabledbooleanfalseMakes every box inert. It uses the real disabled attribute, so they leave the tab order.
variantenum = boxed | underlineboxedThe shape of the boxes. The boxed run is the base class on its own; the underline run adds um-input-otp--underline.
sizeenum = sm | md | lgmdThe size of each box.
readonlybooleanfalseKeeps the code visible but stops it being edited. It is the native readonly attribute, so the browser refuses the edit. The library does not repaint a read-only box — it is not a state it measures.
model-valuestring—The bound code. It answers to `v-model` as well as to `value`, and the binding wins when it is there.

Accessibility

Role: group

Keyboard: Tab Arrow keys Backspace

Each box is a real <input maxlength="1">, so it is in the tab order, the reader can type into it, and a screen reader announces it as a text field. Every box names itself by its position — "Digit 1", "Digit 2" — because a blank box carries no text of its own, and the row itself carries the name of the thing being asked for. The first box asks the browser for the one-time-code autofill, which is where a code arriving by message goes. The library has no script, so it cannot move the caret from one box to the next when a box is filled; that is the host's to do, and the reader can always Tab through the boxes instead.
