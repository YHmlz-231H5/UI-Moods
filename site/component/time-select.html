Time Select 时间选择器

A choice of time of day, as a native <select>. The option list is the platform's own, so the reader gets the system's own picker and its keyboard behaviour; the library draws the field and the arrow around it.

select form since 1.1.0

The times in the list are the host's data, not the library's: a class cannot carry half an hour, so the granularity is written into the markup as the options themselves. What the library draws is the field and the chevron — the platform's arrow is dropped because it does not follow the theme, while the option list is left exactly as the platform draws it, because a popup the reader already knows is worth more than one painted in the mood's colours.

Examples

Half-hour steps · 半小时一档
A select of half-hourly times. The platform's arrow is gone and the library draws its own, because the platform's arrow does not follow the theme; the list that opens is still the platform's.
<div class="um-time-select um-time-select--bordered">
  <select class="um-time-select__select" aria-label="Start time">
    <option class="um-time-select__option" value="09:00" selected>09:00</option>
    <option class="um-time-select__option" value="09:30">09:30</option>
    <option class="um-time-select__option" value="10:00">10:00</option>
    <option class="um-time-select__option" value="10:30">10:30</option>
    <option class="um-time-select__option" value="11:00">11:00</option>
  </select>
  <span class="um-time-select__arrow" aria-hidden="true"></span>
</div>
Filled · 填充
The same field with the border gone and a recessed surface under it. Only the modifier class changes.
<div class="um-time-select um-time-select--filled">
  <select class="um-time-select__select" aria-label="Coffee break">
    <option class="um-time-select__option" value="15:00" selected>15:00</option>
    <option class="um-time-select__option" value="15:30">15:30</option>
    <option class="um-time-select__option" value="16:00">16:00</option>
  </select>
  <span class="um-time-select__arrow" aria-hidden="true"></span>
</div>
States · 状态
A disabled field. It leaves the tab order, and the chosen time stays on screen so the reader can still read it.
<div class="um-time-select um-time-select--bordered">
  <select class="um-time-select__select" aria-label="Reminder time" disabled>
    <option class="um-time-select__option" value="08:00" selected>08:00</option>
    <option class="um-time-select__option" value="08:30">08:30</option>
  </select>
  <span class="um-time-select__arrow" aria-hidden="true"></span>
</div>

Props

NameTypeDefaultDescription
valuestring—The chosen time. It is the select's own value — a class cannot carry a time.
startstring09:00The first time in the list. The list is the host's data: a class cannot carry the times either.
endstring17:00The last time in the list.
stepnumber1800How far apart the times are, in seconds. Half an hour is the default; an hour is 3600.
labelstring—The accessible name of the field. It becomes the select's aria-label, because the library does not draw a label of its own.
disabledbooleanfalseMakes the field inert. It uses the real disabled attribute, so it leaves the tab order.
variantenum = bordered | filledborderedThe surface of the field. The bordered run is the base class on its own; the filled run adds um-time-select--filled.
sizeenum = sm | md | lgmdThe height of the field.

Events

NameDescription
changeFires when a time is chosen. It is the browser's own event on the select — the library installs no listener.

Accessibility

Role: combobox

Keyboard: Tab Arrow keys Enter Escape

The control is a real <select>, so the browser announces it as a combobox, the arrow keys walk the options and the reader's own popup opens it. Give it a real <label for> or an aria-label. The chevron beside it is drawn from two borders and carries no text — it says there is a list, and the browser says what is in it.
