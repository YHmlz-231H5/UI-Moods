Result 结果

The end of a flow: one statement of what happened, a line of explanation, and the way out. It is the whole answer on one screen, not a toast that disappears.

div, span, h2, p, button data since 1.1.0

The library draws the plate the icon sits on and the size of the box, and stops there. The icon itself is the host's: an icon font would pull a font file into every consumer, and an emoji looks different on every operating system, so the slot ships empty and the host fills it with its own SVG.

Examples

A result · 一个结果
The icon slot is empty: the host is meant to put its own SVG in it, so the library does not ship an icon font or an emoji. What the host puts inside inherits the colour of the plate.

Deployment finished

Build 214 passed on all three nodes.

<div class="um-result">
  <span class="um-result__icon" aria-hidden="true"></span>
  <h2 class="um-result__title">Deployment finished</h2>
  <p class="um-result__subtitle">Build 214 passed on all three nodes.</p>
  <div class="um-result__extra">
    <button>View build</button>
  </div>
</div>
Tones · 状态
Four variants tint the plate behind the icon. The tint is the soft one, and the icon takes the foreground derived for that tint, so it stays readable in every mood.

Props

NameTypeDefaultDescription
variantenum = success | warning | danger | info—The tone of the plate behind the icon. Without a variant the plate takes the brand colour.
titlestring—What happened. It should be a real heading element, so the page keeps its outline.
subtitlestring—The line under the title.

Slots

NameDescription
iconThe icon. The slot is empty and takes an SVG from the host.
titleThe headline.
subtitleThe line under the headline.
sub-titleThe line under the headline, under the name Element Plus gives it. It fills the same part as the subtitle slot.
extraThe actions.

Accessibility

The title should be a real heading element — the class sets its size, so the document outline stays right. The icon is decoration: mark the slot aria-hidden, because an icon that repeats the title is read twice. The buttons in the actions area are real buttons, so they are focusable and reachable by keyboard.
