Carousel 轮播图

Slides the reader scrolls through, with a button at each end of a slide that moves to the neighbouring one. The track is a real scroller, so the browser does the scrolling and the snapping.

div data since 1.1.0

The buttons are links, and that is the only way a stylesheet can move a scroller. A checked radio or an open details can change what the page looks like, but no rule in CSS can move a scroll container: the browser scrolls a scroller when a fragment names something inside it, and that is all. So the buttons point at the id of a slide and the browser does the scrolling and the snapping, and the slide they arrive at is the one the fragment names, which is how the current slide is marked. The buttons live in the slide they belong to, so the previous and the next button always point at that slide's neighbours — with a static row of buttons outside the slides, there would be no way to say "the slide before this one" without script. The track is a real scroller, so it is given a tabindex and a name.

Props

NameTypeDefaultDescription
namestring—The prefix of the ids of the slides. Every slide needs an id of its own, because that id is what the buttons point at, and two carousels on one page cannot share ids.
variantenum = plain | spacedplainWhether the slides are edge to edge or have a gap between them. The plain run is the base class on its own; the spaced run adds um-carousel--spaced.
sizeenum = sm | md | lgmdThe size of the caption and of the buttons.
labelstring—The name of the track, read out before the slides. A scrollable region has to carry a name, or the reader is told about a scroll box and nothing else.
arrowenum = always | hover | neveralwaysWhen the buttons that move between the slides are shown. The always run is the base class on its own.
loopbooleantrueWhether the slides wrap around: the first slide's previous button points at the last one, and the last slide's next button points at the first. Turn it off and the ends stop.
typeenum = default | carddefaultHow the slides sit next to each other. The card run is the spaced one: the neighbouring slides show at the edges of the track, so the reader can tell there is more than one.

Slots

NameDescription
defaultThe slides, one figure per slide. Each figure holds the body, the caption and, at its foot, the buttons that move to its neighbours.

Accessibility

Role: group

Keyboard: Tab Arrow keys Home End

The track is a real scroller, so give it tabindex="0" and a name: a scrollable region that the keyboard cannot reach is not operable. The buttons are real links with names, so the reader hears "Next slide" rather than a picture of an arrow. The arrow itself is drawn from borders and is hidden from the reader, so the name on the link is what carries it. A slide that is moved to is marked by the fragment in the address, which the browser also records in its history — so the back button walks back through the slides.
