Skeleton 骨架屏

The shape of content that has not arrived yet. Three placeholder shapes and, if the motion is welcome, a shimmer over them.

div data since 1.1.0

The shimmer is a gradient on a background that is four times wider than the placeholder, moved by one keyframe from one end to the other. The whole rule sits inside prefers-reduced-motion: no-preference, which is the library's way of saying that motion is a thing the user can turn off.

Examples

Shapes · 形状
One shape per kind of placeholder. The width is set inline because it is a measurement, not a shape.
<div class="um-skeleton um-skeleton--text" style="width:80%"></div>
<div class="um-skeleton um-skeleton--text" style="width:55%"></div>
<div class="um-skeleton um-skeleton--circle"></div>
<div class="um-skeleton um-skeleton--block"></div>
Animated · 微光
The shimmer is a background gradient moving across the placeholder. It is inside a prefers-reduced-motion query, so the library never overrides a user who has asked for less motion — the placeholder simply stays still.
<div class="um-skeleton um-skeleton--text um-skeleton--animated" style="width:80%"></div>
<div class="um-skeleton um-skeleton--block um-skeleton--animated"></div>

Props

NameTypeDefaultDescription
shapeenum = text | circle | blocktextWhich placeholder shape to draw.
animatedbooleanfalseShimmers the placeholder while the content loads. The animation is wrapped in a prefers-reduced-motion query, so a user who asked for less motion gets a still placeholder.
widthnumber100How wide the placeholder is, as a percentage of its container. A line of text usually wants a width under 100.

Accessibility

A skeleton is a placeholder, not content: mark it aria-hidden so a screen reader does not read a row of empty boxes, and put aria-busy="true" on the region that is loading. The real content replaces it when it arrives — nothing else is needed.
