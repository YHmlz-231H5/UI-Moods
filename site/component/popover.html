Popover 气泡卡片

A card that floats next to a trigger and holds more than a note: a heading, a body and a row of actions. The trigger is a <summary>, so the card opens and closes with the browser's own disclosure behaviour.

details, summary, div feedback since 1.1.0

The card is hidden with `display: none` and shown again by `[open]`, rather than left to the browser's rendering of a closed <details>. The browser hides a closed details with a slot, which is not guaranteed to catch a child that has been taken out of the flow — and this card is absolutely positioned, so it has been. Two lines of CSS buy a guarantee that the closed card is really gone.

Examples

Basic · 基础用法
A card with a heading, a body and a row of actions. The trigger opens it; the browser owns the open state.
Deployment
Nightly deployment
Six replicas are moved to the new build, one at a time, with a health check between each.
Last run finished in 4 minutes with no differences.
<details class="um-popover">
  <summary class="um-popover__trigger">Deployment</summary>
  <div class="um-popover__content">
    <div class="um-popover__header">Nightly deployment</div>
    <div class="um-popover__body">Six replicas are moved to the new build, one at a time, with a health check between each.</div>
    <div class="um-popover__footer">Last run finished in 4 minutes with no differences.</div>
  </div>
</details>

Props

NameTypeDefaultDescription
placementenum = bottom | top | left | rightbottomWhere the card opens relative to the trigger. The bottom placement is the base class on its own; the other three add um-popover--top, um-popover--left or um-popover--right.
widthenum = small | medium | largemediumHow wide the card is. The measures are in the card's own type, so the card grows with the mood's text instead of holding a fixed pixel width.
titlestring—The heading of the card. It is a real heading element, not a bold paragraph, so the reader can jump to it.

Slots

NameDescription
headerThe heading of the card.

footerThe row at the bottom of the card.

Events

NameDescription
toggleFires when the card opens or closes. It is the browser's own event on the <details> — the library installs no listener.

Accessibility

Role: dialog

Keyboard: Tab Enter Space

The trigger is a <summary>, so the browser announces it as a disclosure button and says whether the card is open. The card is not modal: it does not trap the focus, and whatever is inside it is an ordinary focusable element. Escape does not close it — a CSS-only library has no key handling to add — so the reader closes it with the same trigger they opened it with. Put the heading in a real heading element, so the reader can navigate by it.
