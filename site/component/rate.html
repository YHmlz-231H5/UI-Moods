Rate 评分

A row of stars the reader sets by choosing one. The stars are real radio buttons under a drawn shape, so the value is the browser's own value and the group is the browser's own group.

input, label, span form since 1.1.0

How many stars are filled is read off the checked radio with `:has()`, and written into a variable the items count against — because CSS cannot compare two positions, so the stylesheet carries one rule per star and stops at five. The star itself is a polygon cut out of a square: the library ships no icon font, and a filled star and an empty star are the same shape in two colours, which a glyph font would have had to ship twice.

Props

NameTypeDefaultDescription
valuenumber0How many stars are filled. It is the checked radio's value, not a class — a class cannot carry a number.
maxnumber5How many stars the group has. The stylesheet ships five positions, so a group longer than that needs more rules.
colorenum = primary | success | warning | dangerprimaryThe colour of the filled stars. The primary colour is the base class on its own; the other three add um-rate--success, um-rate--warning or um-rate--danger.
disabledbooleanfalseMakes the group inert. It uses the real disabled attribute on the radios, so it leaves the tab order.
sizeenum = small | medium | largemediumHow big the stars are. The medium size is the base class on its own, so it needs no modifier class.

Events

NameDescription
changeFires when the reader picks another star. It is the browser's own event on the radio underneath — the library installs no listener.

Accessibility

Role: radiogroup

Keyboard: Tab ArrowLeft ArrowRight

The stars are five real radio buttons in one group, so the browser announces the group, moves between the stars with the arrow keys and keeps the chosen one. Each radio needs an accessible name of its own — the label beside it carries no text, because the star is a drawn shape — so give every radio an aria-label such as "3 out of 5". The drawn star is a picture and is hidden from the accessibility tree by the radio's own name; the focus ring goes on the item, because a clipped element cannot show an outline.
