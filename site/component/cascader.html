Cascader 级联选择器

Options in levels, opened one level at a time. Every level is a disclosure, so the browser does the opening and the closing and the state survives a reload.

details, summary data since 1.1.0

A level is a disclosure, not a menu: the browser owns the open state, so the branch stays open across a reload and the reader gets the "collapsed" and "expanded" announcement for free. The level below is hidden with `display: none` and shown again by `[open]`, because in the flyout run the panel is taken out of the flow and the browser's own hiding is not guaranteed to catch that. The mark that says there is a level below is drawn from two borders, so it takes the option's own colour.

Props

NameTypeDefaultDescription
openbooleanfalseOpens a level. It is the native open attribute on the details, so the browser keeps the state.
layoutenum = inline | flyoutinlineWhere the level below opens. The inline run is the base class on its own; the flyout run adds um-cascader--flyout.
sizeenum = sm | md | lgmdThe size of the option text.
labelstring—The text of one option. An option with no text needs an accessible name of its own.
disabledbooleanfalseMakes the cascader inert. A level is a disclosure rather than a form control, so it cannot carry the disabled attribute: the whole tree refuses the pointer instead.

Slots

NameDescription
optionOne option: its text and the mark that says there is a level below it.
childrenThe level below, holding one option per branch.

Events

NameDescription
toggleFires when a level opens or closes. It is the browser's own event on the details — the library installs no listener.

Accessibility

Role: group

Keyboard: Tab Enter Space

Every level is a real <details> and every option is a real <summary>, so the browser announces each option as a disclosure button and says whether its level is open. The keyboard is the browser's own: Tab reaches the options, Enter or Space opens the level below. The arrow is drawn from borders, so it carries no text — the level below is announced by the browser, not by the mark. A library with no JavaScript cannot work out the chosen path, so the path a reader has picked is the host's to write.
