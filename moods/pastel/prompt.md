# Mood: pastel

Pastel is a soft-focus palette: a warm blush ground with lilac, mint and
peach sitting at low saturation, so the page reads as frosted rather than
contrasty. Surfaces are near-white and softly tinted, with wide rounded
corners, capsule buttons and hairline borders in a dusty mauve that never
draws attention to itself. Type is Quicksand — round, even, friendly — at a
moderate display size with nothing heavy on the page. Shadows are lavender and
diffuse instead of grey, so depth feels like soft light rather than weight.
Motion is a gentle ease-out that lets elements arrive without ever being
sharp. The overall effect is calm, welcoming and a little dreamy — a page
that feels like it is speaking in a lowered voice.

## Keywords

`pastel`, `soft`, `low-saturation`, `friendly`

## When to use

- Wellness, skincare, childcare and community products with a gentle voice
- Onboarding, empty states and settings screens that should feel unintimidating

## When to avoid

- Dashboards where low-contrast status colours need to be read instantly
- Dense, high-stakes interfaces where soft edges reduce urgency and hierarchy
