# Mood: glass

Glass is a dark, luminous interface built from translucent panels floating
over soft gradient light blobs. Panels read as frosted glass: blurred
backgrounds, hairline highlights and a calm violet-to-cyan glow. It feels
airy, modern and slightly futuristic — best for dashboards, workspaces and
showcase screens.

## Keywords

`frosted`, `backdrop-blur`, `translucent`, `glow`, `dark`

## When to use

- Dashboards and tool workspaces where depth and layering help navigation
- Landing or showcase screens that should feel premium and light

## When to avoid

- Dense data tables that need maximum contrast on every cell
- Light-on-light content where blur would reduce legibility
