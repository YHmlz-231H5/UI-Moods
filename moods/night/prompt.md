# Mood: night

Night is a deep-blue technical interface with glowing cyan readouts — tools
for operating after dark. Monospace rhythm, hairline glows and translucent
panels make every value feel live and trustworthy.

## Keywords

`night`, `blue`, `glow`, `monospace`, `dark`

## When to use

- Monitoring, ops and data-tool interfaces
- Dark-mode workspaces where information needs a calm, luminous hierarchy

## When to avoid

- Light editorial or consumer content that needs warmth
