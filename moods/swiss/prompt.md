# Mood: swiss

Swiss is a typographic system, not a decoration. Everything sits on a strict
grid of white space with a single hairline rule doing the structural work, and
one signal red reserved for the element that actually matters. Type is the
material: a large, tightly-tracked grotesque set flush left against generous
margins, with labels cut small and wide-tracked. There are no shadows at all —
depth is replaced by alignment, scale and air. Motion is brief and nearly
invisible, a plain ease that keeps the layout still. It feels rational, exact
and quietly confident: the visual language of a printed annual report or a
museum exhibition wall.

## Keywords

`swiss`, `helvetica`, `grid`, `red-accent`

## When to use

- Editorial, report and documentation layouts where reading order rules
- Portfolio and consultancy sites that want credibility through restraint

## When to avoid

- Consumer products that need warmth, playfulness or emotional appeal
- Interfaces where a hairline-only system needs stronger visual affordance
