# Mood: blueprint

Blueprint is a technical drafting interface on deep-blue paper: white ink
lines, uppercase condensed display type and a grid-and-tabular feel. It looks
like an engineer's drawing sheet come to life.

## Keywords

`blueprint`, `drafting`, `uppercase`, `technical`, `blueprint-paper`

## When to use

- Engineering, architecture and planning tools
- Anything that should read as precise, drafted and structural

## When to avoid

- Warm, editorial or consumer-facing content
