# Mood: archive

Archive is a warm paper-and-ink interface: serif body text, dashed hairlines,
stamp-like accents and a slightly aged paper palette. It feels like a
well-kept library catalogue or a vintage journal.

## Keywords

`archive`, `paper`, `serif`, `stamp`, `ink`

## When to use

- Editorial, documentation and catalogue-style UIs
- Content that should feel trustworthy and slightly timeless

## When to avoid

- Dense tool dashboards that need compact sans-serif rhythm
