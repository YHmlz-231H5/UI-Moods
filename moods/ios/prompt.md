# Mood: ios

iOS is Apple-like clarity: system type, rounded grouped cards, translucent
surfaces and system blue. It feels calm, crisp and immediate — the interface
should be so legible that it disappears.

## Keywords

`sf-pro`, `rounded`, `grouped`, `system-blue`

## When to use

- Mobile-style settings, forms and utility screens
- Products that should feel native, familiar and effortless

## When to avoid

- Experimental or highly-branded visual statements
