Send your first event

Beacon receives events over a single HTTP endpoint. Everything you need to ship a working integration is one request, one JSON body and one identifier that ties a person to their history.

Note
Events are sampled after ingestion. The raw payload is written to your bucket first, so nothing is lost even when the workspace applies sampling for reporting.

The event envelope

Every event carries a name, a timestamp and a user. Properties are free-form and are queryable within 90 days on every plan.

JSONPOST /v1/events
{
  "event": "checkout_completed",
  "user": { "id": "usr_8841" },
  "properties": {
    "plan": "pro",
    "amount_cents": 7900,
    "currency": "EUR"
  },
  "occurred_at": "2026-11-10T09:41:22Z"
}

Required properties

Only two fields are mandatory. Everything else has a sensible default so you can ship before the schema is settled.

FieldTypeRequiredNotes
eventstringYesLowercase, dots allowed
user.idstringYesPseudonymous, never an email
occurred_attimestampNoDefaults to receipt time
propertiesobjectNoUp to 64 keys per event

Verify from the console

Open the Events tab and watch the first payload arrive. If it does not show up within 30 seconds, check the workspace key and the source allow-list.
